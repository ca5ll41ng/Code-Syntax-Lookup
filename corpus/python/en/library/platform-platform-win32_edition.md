# win32_edition

Returns a string representing the current Windows edition, or `None` if the
value cannot be determined.  Possible values include but are not limited to
`'Enterprise'`, `'IoTUAP'`, `'ServerStandard'`, and `'nanoserver'`.

> *Added in 3.8*
