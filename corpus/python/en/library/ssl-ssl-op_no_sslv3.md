# OP_NO_SSLv3

Prevents an SSLv3 connection.  This option is only applicable in
conjunction with `PROTOCOL_TLS`.  It prevents the peers from
choosing SSLv3 as the protocol version.

> *Added in 3.2*

> *Deprecated since 3.6*: SSLv3 is deprecated
