# SSLContext.sslsocket_class

The return type of `SSLContext.wrap_socket`, defaults to
`SSLSocket`. The attribute can be assigned to on instances of
`SSLContext` in order to return a custom subclass of
`SSLSocket`.

> *Added in 3.7*
