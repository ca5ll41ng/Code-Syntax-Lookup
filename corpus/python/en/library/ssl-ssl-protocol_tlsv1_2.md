# PROTOCOL_TLSv1_2

Selects TLS version 1.2 as the channel encryption protocol.
Available only with openssl version 1.0.1+.

> *Added in 3.4*

> *Deprecated since 3.6*: OpenSSL has deprecated all version specific protocols.
