# pprint(object, stream=None, indent=1, width=80, depth=None, *, \

Alias for `~pprint.pp` with *sort_dicts* set to `True` by default,
which would automatically sort the dictionaries' keys,
you might want to use `~pprint.pp` instead where it is `False` by default.
