# frozendict

Create a new frozen dictionary.  The `frozendict` object is a built-in class.
See also `typesmapping` for documentation about this class.

For other containers see the built-in `dict`, `list`, `set`,
and `tuple` classes, as well as the `collections` module.

> *Added in 3.15*
