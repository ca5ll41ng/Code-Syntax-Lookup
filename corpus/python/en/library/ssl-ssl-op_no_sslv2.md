# OP_NO_SSLv2

Prevents an SSLv2 connection.  This option is only applicable in
conjunction with `PROTOCOL_TLS`.  It prevents the peers from
choosing SSLv2 as the protocol version.

> *Added in 3.2*

> *Deprecated since 3.6*: SSLv2 is deprecated
