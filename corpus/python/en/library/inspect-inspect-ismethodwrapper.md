# ismethodwrapper

Return `True` if the type of object is a `~types.MethodWrapperType`.

These are instances of `~types.MethodWrapperType`, such as `~object.__str__`,
`~object.__eq__` and `~object.__repr__`.

> *Added in 3.11*
