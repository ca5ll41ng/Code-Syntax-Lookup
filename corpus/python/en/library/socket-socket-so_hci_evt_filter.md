# SO_HCI_EVT_FILTER

Option names for use with `BTPROTO_HCI`.
Availability and format of the option values depend on platform.

> *Changed in 3.14*: Added :const:`!SO_HCI_EVT_FILTER` and :const:`!SO_HCI_PKT_FILTER` on NetBSD and DragonFly BSD. Added :const:`!HCI_DATA_DIR` on FreeBSD, NetBSD and DragonFly BSD.
