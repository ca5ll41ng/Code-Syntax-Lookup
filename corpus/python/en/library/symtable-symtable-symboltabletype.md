# SymbolTableType

An enumeration indicating the type of a `SymbolTable` object.

attribute:: MODULE

attribute:: FUNCTION

attribute:: CLASS

attribute:: INLINED_COMPREHENSION

The following members refer to different flavors of
`annotation scopes`.

attribute:: ANNOTATION

attribute:: TYPE_ALIAS

attribute:: TYPE_PARAMETERS

attribute:: TYPE_VARIABLE

> *Added in 3.13*
