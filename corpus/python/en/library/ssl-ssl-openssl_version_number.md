# OPENSSL_VERSION_NUMBER

The raw version number of the OpenSSL library, as a single integer::

 >>> ssl.OPENSSL_VERSION_NUMBER
 268443839
 >>> hex(ssl.OPENSSL_VERSION_NUMBER)
 '0x100020bf'

> *Added in 3.2*
