# log2

Return the base-2 logarithm of *x*. This is usually more accurate than
`log(x, 2)`.

> *Added in 3.3*

> **Seealso**
>
> `int.bit_length` returns the number of bits necessary to represent
> an integer in binary, excluding the sign and leading zeros.
