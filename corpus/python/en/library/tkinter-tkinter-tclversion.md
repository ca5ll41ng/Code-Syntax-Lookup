# TclVersion

The major and minor version of the Tk and Tcl libraries that were used
for building the `_tkinter` module, as floats, for example `8.6`.
Prefer `TK_VERSION_INFO` and `TCL_VERSION_INFO`, which are
more precise and compare correctly.
