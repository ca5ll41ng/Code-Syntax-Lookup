# KEY_ALL_ACCESS

Combines the STANDARD_RIGHTS_REQUIRED, `KEY_QUERY_VALUE`,
`KEY_SET_VALUE`, `KEY_CREATE_SUB_KEY`,
`KEY_ENUMERATE_SUB_KEYS`, `KEY_NOTIFY`,
and `KEY_CREATE_LINK` access rights.
