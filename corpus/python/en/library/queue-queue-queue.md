# Class `multiprocessing.Queue`

> **Seealso**
>
> Class `multiprocessing.Queue`
>    A queue class for use in a multi-processing (rather than multi-threading)
>    context.
>
> `collections.deque` is an alternative implementation of unbounded
> queues with fast atomic `~collections.deque.append` and
> `~collections.deque.popleft` operations that do not require locking
> and also support indexing.
