# Tuple

Deprecated alias for `tuple`.

`tuple` and `Tuple` are special-cased in the type system; see
`annotating-tuples` for more details.

> *Deprecated since 3.9*: :class:`builtins.tuple <tuple>` now supports subscripting (``[]``). See :pep:`585` and :ref:`types-genericalias`.
