# CLOCK_MONOTONIC_RAW_APPROX

Similar to `CLOCK_MONOTONIC_RAW`, but reads a value cached by
the system at context switch and hence has less accuracy.

availability:: macOS >= 10.12.

> *Added in 3.13*
