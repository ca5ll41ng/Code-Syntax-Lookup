# SOL_RFCOMM

Used in the level argument to the `~socket.setsockopt` and
`~socket.getsockopt` methods of Bluetooth socket objects.

`SOL_BLUETOOTH` is only available on Linux. Other constants
are available if the corresponding protocol is supported.
