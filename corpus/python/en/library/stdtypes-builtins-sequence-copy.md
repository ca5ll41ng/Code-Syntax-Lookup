# sequence.copy

> *Added in 3.3*

Create a shallow copy of *sequence*.
This is equivalent to writing `sequence[:]`.

> **Hint**
>
> `~collections.abc.MutableSequence` `~abc.ABC`,
> but most concrete mutable sequence types provide it.
>
