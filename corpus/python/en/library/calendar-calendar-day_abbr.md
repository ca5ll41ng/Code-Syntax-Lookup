# day_abbr

A sequence that represents the abbreviated days of the week in the current locale,
where Mon is day number 0.

    >>> import calendar
    >>> list(calendar.day_abbr)
    ['Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat', 'Sun']
