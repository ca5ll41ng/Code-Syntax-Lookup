# get_default_scheme

Return the default scheme name for the current platform.

> *Added in 3.10*: This function was previously named ``_get_default_scheme()`` and considered an implementation detail.

> *Changed in 3.11*: When Python runs from a virtual environment, the *venv* scheme is returned.
