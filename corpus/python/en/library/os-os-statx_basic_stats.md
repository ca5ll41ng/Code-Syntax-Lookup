# STATX_BASIC_STATS

Bitflags for use in the *mask* parameter to `os.statx`.  Some of these
flags may be available even when their corresponding members in
`statx_result` are not available.

availability:: Linux >= 4.11 with glibc >= 2.28.

> *Added in 3.15*
