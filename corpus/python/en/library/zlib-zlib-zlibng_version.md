# ZLIBNG_VERSION

The version string of the zlib-ng library that was used for building the
module if zlib-ng was used. When present, the `ZLIB_VERSION` and
`zlib_version` constants reflect the version of the zlib API
provided by zlib-ng.

> *Added in 3.14*
