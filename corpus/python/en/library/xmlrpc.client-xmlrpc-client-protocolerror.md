# ProtocolError

A `ProtocolError` object describes a protocol error in the underlying
transport layer (such as a 404 'not found' error if the server named by the URI
does not exist).  It has the following attributes:

attribute:: url

attribute:: errcode

attribute:: errmsg

attribute:: headers
