# _clear_type_cache

This function is a no-op. It used to clear the internal type cache, which
is now implemented per-type.

> *Deprecated since 3.13*: Use the more general :func:`_clear_internal_caches` function instead.

> *Changed in 3.16*: This function is now a no-op.
