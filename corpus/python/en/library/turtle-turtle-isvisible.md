# isvisible

Return `True` if the Turtle is shown, `False` if it's hidden.

```python
:skipif: _tkinter is None

>>> turtle.hideturtle()
>>> turtle.isvisible()
False
>>> turtle.showturtle()
>>> turtle.isvisible()
True
```
