# uname_result

Name and information about the system returned by `os.uname`.
These attributes correspond to the members described in `uname(2)`.

For backwards compatibility, this object is also iterable, behaving
like a five-tuple containing `~uname_result.sysname`,
`~uname_result.nodename`, `~uname_result.release`,
`~uname_result.version`, and `~uname_result.machine`
in that order.

attribute:: sysname

attribute:: nodename

attribute:: release

attribute:: version

attribute:: machine
