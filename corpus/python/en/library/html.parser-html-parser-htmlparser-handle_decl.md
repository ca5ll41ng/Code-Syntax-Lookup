# HTMLParser.handle_decl

This method is called to handle an HTML doctype declaration (e.g.
`<!DOCTYPE html>`).

The *decl* parameter will be the entire contents of the declaration inside
the `<!...>` markup (e.g. `'DOCTYPE html'`).
