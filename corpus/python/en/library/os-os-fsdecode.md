# fsdecode

Decode the `path-like` *filename* from the
`filesystem encoding and error handler`; return `str`
unchanged.

`fsencode` is the reverse function.

> *Added in 3.2*

> *Changed in 3.6*: Support added to accept objects implementing the :class:`os.PathLike` interface.
