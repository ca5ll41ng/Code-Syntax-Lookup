# FILTER_LZMA1

The LZMA1 and LZMA2 compression filters.  `FILTER_LZMA1` is for use
with `FORMAT_ALONE`, while `FILTER_LZMA2` is for use with
`FORMAT_XZ` and `FORMAT_RAW`.
