# LabeledScale

A `Frame` containing a `Scale` and a `Label` that shows
the scale's current value.
*variable* is the `~tkinter.IntVar` tracked by the scale (one is
created if it is not given), and *from_* and *to* define the range of the
scale.

method:: destroy()
