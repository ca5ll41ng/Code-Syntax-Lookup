# block

Returns the `block
<https://www.unicode.org/versions/Unicode18.0.0/core-spec/chapter-3/#G64189>`_
assigned to the character *chr*. For example::

   >>> unicodedata.block('S')
   'Basic Latin'

> *Added in 3.15*
