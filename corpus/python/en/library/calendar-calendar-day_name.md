# day_name

A sequence that represents the days of the week in the current locale,
where Monday is day number 0.

    >>> import calendar
    >>> list(calendar.day_name)
    ['Monday', 'Tuesday', 'Wednesday', 'Thursday', 'Friday', 'Saturday', 'Sunday']
