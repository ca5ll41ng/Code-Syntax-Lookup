# URLError

The handlers raise this exception (or derived exceptions) when they run into
a problem.  It is a subclass of `OSError`.

attribute:: reason

> *Changed in 3.3*: :exc:`URLError` used to be a subtype of :exc:`IOError`, which is now an alias of :exc:`OSError`.
