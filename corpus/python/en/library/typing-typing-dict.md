# Dict

Deprecated alias to `dict`.

Note that to annotate arguments, it is preferred
to use an abstract collection type such as `~collections.abc.Mapping`
rather than to use `dict` or `typing.Dict`.

> *Deprecated since 3.9*: :class:`builtins.dict <dict>` now supports subscripting (``[]``). See :pep:`585` and :ref:`types-genericalias`.
