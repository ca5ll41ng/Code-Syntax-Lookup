# hStdError=None, wShowWindow=0, lpAttributeList=None)

Partial support of the Windows
[STARTUPINFO](https://msdn.microsoft.com/en-us/library/ms686331(v=vs.85).aspx)
structure is used for `Popen` creation.  The following attributes can
be set by passing them as keyword-only arguments.

> *Changed in 3.7*: Keyword-only argument support was added.

attribute:: dwFlags

attribute:: hStdInput

attribute:: hStdOutput

attribute:: hStdError

attribute:: wShowWindow

attribute:: lpAttributeList
