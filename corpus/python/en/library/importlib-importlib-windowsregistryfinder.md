# WindowsRegistryFinder

`Finder` for modules declared in the Windows registry.  This class
implements the `importlib.abc.MetaPathFinder` ABC.

Only class methods are defined by this class to alleviate the need for
instantiation.

> *Added in 3.3*

> *Deprecated since 3.6*: Use :mod:`site` configuration instead. Future versions of Python may not enable this finder by default.
