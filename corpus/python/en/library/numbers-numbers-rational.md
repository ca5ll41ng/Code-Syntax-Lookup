# Rational

Subtypes `Real` and adds `~Rational.numerator` and
`~Rational.denominator` properties. It also provides a default for
`float`.

The `~Rational.numerator` and `~Rational.denominator` values
should be instances of `Integral` and should be in lowest terms with
`~Rational.denominator` positive.

attribute:: numerator

attribute:: denominator
