# library

Name of the NDBM implementation library used:
`'GNU gdbm'`, `'Berkeley DB'` or `'ndbm'`.

> *Changed in next*: The value is ``'ndbm'`` for a classic NDBM library. It was ``'GNU gdbm'`` before.
