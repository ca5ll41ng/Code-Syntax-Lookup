# Callable

:class:`collections.abc.Callable` 的已弃用的别名。

See `annotating-callables` for details on how to use
`collections.abc.Callable` and `typing.Callable` in type annotations.

> *Deprecated since 3.9*: :class:`collections.abc.Callable` now supports subscripting (``[]``). See :pep:`585` and :ref:`types-genericalias`.

> *Changed in 3.10*: ``Callable`` now supports :class:`ParamSpec` and :data:`Concatenate`. See :pep:`612` for more details.
