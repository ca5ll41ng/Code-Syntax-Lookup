# fsencode

Encode `path-like` *filename* to the
`filesystem encoding and error handler`; return `bytes`
unchanged.

:func:`fsdecode` 是此函数的逆向函数。

> *Added in 3.2*

> *Changed in 3.6*: Support added to accept objects implementing the :class:`os.PathLike` interface.
