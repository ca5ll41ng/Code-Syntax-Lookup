# CLOCK_TAI

`国际原子时间 <https://www.nist.gov/pml/time-and-frequency-division/how-utcnist-related-coordinated-universal-time-utc-international>`_

The system must have a current leap second table in order for this to give
the correct answer.  PTP or NTP software can maintain a leap second table.

availability:: Linux.
