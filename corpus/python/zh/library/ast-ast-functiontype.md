# FunctionType

A representation of an old-style type comments for functions,
as Python versions prior to 3.5 didn't support PEP 484 annotations.
Node type generated by `ast.parse` when *mode* is `"func_type"`.

此种类型注释的形式是这样的::

    def sum_two_number(a, b):
        # type: (int, int) -> int
        return a + b

``argtypes`` 是由 :ref:`表达式节点 <ast-expressions>` 组成的 :class:`list`。

``returns`` 是单独的 :ref:`表达式节点 <ast-expressions>`。

```python

>>> print(ast.dump(ast.parse('(int, str) -> List[int]', mode='func_type'), indent=4))
FunctionType(
    argtypes=[
        Name(id='int'),
        Name(id='str')],
    returns=Subscript(
        value=Name(id='List'),
        slice=Name(id='int')))
```

> *Added in 3.8*
