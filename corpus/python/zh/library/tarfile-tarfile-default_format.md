# DEFAULT_FORMAT

用于创建归档的默认格式。目前为 :const:`PAX_FORMAT`。

> *Changed in 3.8*: The default format for new archives was changed to :const:`PAX_FORMAT` from :const:`GNU_FORMAT`.
