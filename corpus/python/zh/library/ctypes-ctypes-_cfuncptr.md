# _CFuncPtr

C 可调用外部函数的基类。

Instances of foreign functions are also C compatible data types; they
represent C function pointers.

This behavior can be customized by assigning to special attributes of the
foreign function object.

attribute:: restype

attribute:: argtypes

attribute:: errcheck
