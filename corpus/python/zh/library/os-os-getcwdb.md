# getcwdb

返回表示当前工作目录的字节串 (bytestring)。

> *Changed in 3.8*: The function now uses the UTF-8 encoding on Windows, rather than the ANSI code page: see :pep:`529` for the rationale. The function is no longer deprecated on Windows.
