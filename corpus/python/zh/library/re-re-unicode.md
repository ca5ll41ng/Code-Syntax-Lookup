# UNICODE

In Python 3, Unicode characters are matched by default
for `str` patterns.
This flag is therefore redundant with **no effect**
and is only kept for backward compatibility.

请参阅 :py:const:`~re.ASCII` 了解如何改为仅限匹配 ASCII 字符。
