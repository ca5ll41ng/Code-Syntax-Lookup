# CAN_RAW_JOIN_FILTERS

Joins the applied CAN filters such that only CAN frames that match all
given CAN filters are passed to user space.

此常量在 Linux 文档中有所记载。

availability:: Linux >= 4.1.

> *Added in 3.9*
