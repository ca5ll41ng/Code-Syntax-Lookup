# filemode

将文件模式转换为 '-rwxrwxrwx' 形式的字符串。

> *Added in 3.3*

> *Changed in 3.4*: The function supports :data:`S_IFDOOR`, :data:`S_IFPORT` and :data:`S_IFWHT`.
