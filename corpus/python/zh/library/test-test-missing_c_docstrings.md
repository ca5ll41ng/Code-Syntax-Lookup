# MISSING_C_DOCSTRINGS

Set to `True` if Python is built without docstrings (the
:c`WITH_DOC_STRINGS` macro is not defined).
See the `configure --without-doc-strings` option.

另请参阅 :data:`HAVE_DOCSTRINGS` 变量。
