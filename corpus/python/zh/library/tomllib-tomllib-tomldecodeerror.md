# TOMLDecodeError

拥有以下附加属性的 :exc:`ValueError` 的子类：

attribute:: msg

attribute:: doc

attribute:: pos

attribute:: lineno

attribute:: colno

> *Changed in 3.14*: Added the *msg*, *doc* and *pos* parameters. Added the :attr:`msg`, :attr:`doc`, :attr:`pos`, :attr:`lineno` and :attr:`colno` attributes.

> *Deprecated since 3.14*: Passing free-form positional arguments is deprecated.
