# GSSName.toString

```java
String toString()
```

Returns a textual representation of the GSSName object.  To retrieve
 the printed name format, which determines the syntax of the returned
 string, use the `getStringNameType() getStringNameType`
 method.

**返回**

- a String representing this name in printable form.
