# PartitionOperation.partition

```java
int[] partition(A a, int low, int high, int pivotIndex1, int pivotIndex2)
```

Partitions the specified range of the array using the given pivots.

**参数**

- **a** — the array to be partitioned
- **low** — the index of the first element, inclusive, to be partitioned
- **high** — the index of the last element, exclusive, to be partitioned
- **pivotIndex1** — the index of pivot1, the first pivot
- **pivotIndex2** — the index of pivot2, the second pivot
