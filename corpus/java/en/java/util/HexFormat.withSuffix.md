# HexFormat.withSuffix

```java
public HexFormat withSuffix(String suffix)
```

Returns a copy of this `HexFormat` with the suffix.

**参数**

- **suffix** — a suffix, non-null, may be empty

**返回**

- a copy of this `HexFormat` with the suffix
