# BitSet.length

```java
public int length()
```

Returns the "logical size" of this `BitSet`: the index of
 the highest set bit in the `BitSet` plus one. Returns zero
 if the `BitSet` contains no set bits.

**返回**

- the logical size of this `BitSet`

> *Since 1.2*
