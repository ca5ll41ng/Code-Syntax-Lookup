# GregorianCalendar.isWeekDateSupported

```java
public final boolean isWeekDateSupported()
```

Returns `true` indicating this `GregorianCalendar`
 supports week dates.

**返回**

- `true` (always)

**参见**

- #getWeekYear()
- #setWeekDate(int,int,int)
- #getWeeksInWeekYear()
