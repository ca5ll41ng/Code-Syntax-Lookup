# Attributes.remove

```java
public Object remove(Object name)
```

Removes the attribute with the specified name (key) from this Map.
 Returns the previous attribute value, or null if none.

**参数**

- **name** — attribute name

**返回**

- the previous value of the attribute, or null if none
