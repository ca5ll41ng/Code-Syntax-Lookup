# BitSet.andNot

```java
public void andNot(BitSet set)
```

Clears all of the bits in this `BitSet` whose corresponding
 bit is set in the specified `BitSet`.

**参数**

- **set** — the `BitSet` with which to mask this `BitSet`

> *Since 1.2*
