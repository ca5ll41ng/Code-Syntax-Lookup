# BitSet.flip

```java
public void flip(int bitIndex)
```

Sets the bit at the specified index to the complement of its
 current value.

**参数**

- **bitIndex** — the index of the bit to flip

**异常**

- **IndexOutOfBoundsException** — if the specified index is negative

> *Since 1.4*
