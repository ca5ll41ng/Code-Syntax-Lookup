# HexFormat.withPrefix

```java
public HexFormat withPrefix(String prefix)
```

Returns a copy of this `HexFormat` with the prefix.

**参数**

- **prefix** — a prefix, non-null, may be empty

**返回**

- a copy of this `HexFormat` with the prefix
