# Set.size

```java
int size()
```

Returns the number of elements in this set (its cardinality).  If this
 set contains more than `Integer.MAX_VALUE` elements, returns
 `Integer.MAX_VALUE`.

**返回**

- the number of elements in this set (its cardinality)
