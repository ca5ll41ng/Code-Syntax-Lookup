# EnumMap.EnumMap

```java
public EnumMap(Class<K> keyType)
```

Creates an empty enum map with the specified key type.

**参数**

- **keyType** — the class object of the key type for this enum map

**异常**

- **NullPointerException** — if `keyType` is null
