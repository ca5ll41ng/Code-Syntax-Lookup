# Locale.stripExtensions

```java
public Locale stripExtensions()
```

Returns a copy of this `Locale` with no `#def_extensions
 extensions`. If this `Locale` has no extensions, this `Locale`
 is returned.

**返回**

- a copy of this `Locale` with no extensions, or `this` if `this` has no extensions

> *Since 1.8*
