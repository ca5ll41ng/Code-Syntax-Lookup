# Map.of

```java
static <K, V> Map<K, V> of()
```

Returns an unmodifiable map containing zero mappings.
 See Unmodifiable Maps for details.

**参数**

- **the** — `Map`'s key type
- **the** — `Map`'s value type

**返回**

- an empty `Map`

> *Since 9*
