# AtomicReferenceArray.setOpaque

```java
public final void setOpaque(int i, E newValue)
```

Sets the element at index `i` to `newValue`,
 with memory effects as specified by `setOpaque`.

**参数**

- **i** — the index
- **newValue** — the new value

> *Since 9*
