# AtomicIntegerArray.setRelease

```java
public final void setRelease(int i, int newValue)
```

Sets the element at index `i` to `newValue`,
 with memory effects as specified by `setRelease`.

**参数**

- **i** — the index
- **newValue** — the new value

> *Since 9*
