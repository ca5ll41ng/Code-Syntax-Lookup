# AtomicInteger.setPlain

```java
public final void setPlain(int newValue)
```

Sets the value to `newValue`, with memory semantics
 of setting as if the variable was declared non-`volatile`
 and non-`final`.

**参数**

- **newValue** — the new value

> *Since 9*
