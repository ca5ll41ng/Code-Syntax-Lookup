# KeySetView

A view of a ConcurrentHashMap as a `Set` of keys, in
 which additions may optionally be enabled by mapping to a
 common value.  This class cannot be directly instantiated.
 See `keySet`,
 `keySet`,
 `newKeySet`,
 `newKeySet`.

**参数**

- **the** — type of keys
- **the** — type of values in the backing map

> *Since 1.8*
