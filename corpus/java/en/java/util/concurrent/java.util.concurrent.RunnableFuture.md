# RunnableFuture

A `Future` that is `Runnable`. Successful execution of
 the `run` method causes completion of the `Future`
 and allows access to its results.

**参数**

- **The** — result type returned by this Future's `get` method

**参见**

- FutureTask
- Executor

> *Since 1.6*
