# RunnableScheduledFuture.isPeriodic

```java
boolean isPeriodic()
```

Returns `true` if this task is periodic. A periodic task may
 re-run according to some schedule. A non-periodic task can be
 run only once.

**返回**

- `true` if this task is periodic
