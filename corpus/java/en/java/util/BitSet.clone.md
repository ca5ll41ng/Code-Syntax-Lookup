# BitSet.clone

```java
public Object clone()
```

Cloning this `BitSet` produces a new `BitSet`
 that is equal to it.
 The clone of the bit set is another bit set that has exactly the
 same bits set to `true` as this bit set.

**返回**

- a clone of this bit set

- #size()
