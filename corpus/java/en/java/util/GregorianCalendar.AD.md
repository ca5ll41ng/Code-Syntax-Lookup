# GregorianCalendar.AD

```java
public static final int AD = 1
```

Value of the `ERA` field indicating
 the common era (Anno Domini), also known as CE.
 The sequence of years at the transition from `BC` to `AD` is
 ..., 2 BC, 1 BC, 1 AD, 2 AD,...
