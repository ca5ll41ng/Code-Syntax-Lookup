# DoubleStream.sorted

```java
DoubleStream sorted()
```

Returns a stream consisting of the elements of this stream in sorted
 order. The elements are compared for equality according to
 `compare`.

 

This is a stateful
 intermediate operation.

**返回**

- the result stream
