# DoubleStream.boxed

```java
Stream<Double> boxed()
```

Returns a `Stream` consisting of the elements of this stream,
 boxed to `Double`.

 

This is an intermediate
 operation.

**返回**

- a `Stream` consistent of the elements of this stream, each boxed to a `Double`
