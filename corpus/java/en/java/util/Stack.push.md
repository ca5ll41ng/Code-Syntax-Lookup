# Stack.push

```java
public E push(E item)
```

Pushes an item onto the top of this stack. This has exactly
 the same effect as:
 
```

 addElement(item)
```

**参数**

- **item** — the item to be pushed onto this stack.

**返回**

- the `item` argument.

**参见**

- java.util.Vector#addElement
