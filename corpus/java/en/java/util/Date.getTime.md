# Date.getTime

```java
public long getTime()
```

Returns the number of milliseconds since January 1, 1970, 00:00:00 GMT
 represented by this `Date` object.

**返回**

- the number of milliseconds since January 1, 1970, 00:00:00 GMT represented by this date.
