# Calendar.setFirstDayOfWeek

```java
public void setFirstDayOfWeek(int value)
```

Sets what the first day of the week is; e.g., `SUNDAY` in the U.S.,
 `MONDAY` in France.

**参数**

- **value** — the given first day of the week.
