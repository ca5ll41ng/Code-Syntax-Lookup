# LinkedList.push

```java
public void push(E e)
```

Pushes an element onto the stack represented by this list.  In other
 words, inserts the element at the front of this list.

 

This method is equivalent to `addFirst`.

**参数**

- **e** — the element to push

> *Since 1.6*
