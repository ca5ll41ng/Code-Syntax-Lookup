# Handler.Handler

```java
protected Handler()
```

Default constructor.  The resulting `Handler` has a log
 level of `Level.ALL`, no `Formatter`, and no
 `Filter`.  A default `ErrorManager` instance is installed
 as the `ErrorManager`.
