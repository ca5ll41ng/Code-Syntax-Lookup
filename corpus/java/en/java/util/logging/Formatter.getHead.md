# Formatter.getHead

```java
public String getHead(Handler h)
```

Return the header string for a set of formatted records.
 

 This base class returns an empty string, but this may be
 overridden by subclasses.

**参数**

- **h** — The target handler (can be null)

**返回**

- header string
