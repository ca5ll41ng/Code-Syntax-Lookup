# ZipInputStream.ZipInputStream

```java
public ZipInputStream(InputStream in)
```

Creates a new ZIP input stream.

 

The UTF-8 `java.nio.charset.Charset charset` is used to
 decode the entry names.

**参数**

- **in** — the actual input stream
