# URI.hashCode

```java
public int hashCode()
```

Returns a hash-code value for this URI.  The hash code is based upon all
 of the URI's components, and satisfies the general contract of the
 `hashCode() Object.hashCode` method.

**返回**

- A hash-code value for this URI
