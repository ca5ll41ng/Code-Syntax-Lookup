# HttpURLConnection.responseCode

```java
protected int responseCode = -1
```

An `int` representing the three digit HTTP Status-Code.
 
 
-  1xx: Informational
 
-  2xx: Success
 
-  3xx: Redirection
 
-  4xx: Client Error
 
-  5xx: Server Error
