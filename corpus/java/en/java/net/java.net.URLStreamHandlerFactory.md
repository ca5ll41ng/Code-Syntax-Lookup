# URLStreamHandlerFactory

This interface defines a factory for `URL` stream
 protocol handlers.

 

 A URL stream handler factory is used as specified in the
 `URL(String,String,int,String) URL constructor`.

**参见**

- java.net.URL
- java.net.URLStreamHandler

> *Since 1.0*
