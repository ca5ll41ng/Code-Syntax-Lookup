# DatagramPacket.setAddress

```java
public synchronized void setAddress(InetAddress iaddr)
```

Sets the IP address of the machine to which this datagram
 is being sent.

**参数**

- **iaddr** — the `InetAddress`, or `null`.

- #getAddress()
