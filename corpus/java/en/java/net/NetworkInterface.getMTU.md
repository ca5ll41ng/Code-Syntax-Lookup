# NetworkInterface.getMTU

```java
public int getMTU() throws SocketException
```

Returns the Maximum Transmission Unit (MTU) of this interface.

**返回**

- the value of the MTU for that interface.

**异常**

- **SocketException** — if an I/O error occurs.

> *Since 1.6*
