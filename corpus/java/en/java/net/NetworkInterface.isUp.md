# NetworkInterface.isUp

```java
public boolean isUp() throws SocketException
```

Returns whether a network interface is up and running.

**返回**

- `true` if the interface is up and running.

**异常**

- **SocketException** — if an I/O error occurs.

> *Since 1.6*
