# StandardSocketOptions

Defines the standard socket options.

 

 The `name name` of each socket option defined by this
 class is its field name.

 

 In this release, the socket options defined here are used by `java.nio.channels.NetworkChannel network` channels in the `java.nio.channels channels` package.

> *Since 1.7*
