# SocketOption

A socket option associated with a socket.

 

 In the `java.nio.channels channels` package, the `java.nio.channels.NetworkChannel` interface defines the `setOption(SocketOption,Object) setOption`
 and `getOption(SocketOption) getOption`
 methods to set and query the channel's socket options.

**参数**

- **The** — type of the socket option value.

**参见**

- StandardSocketOptions

> *Since 1.7*
