# DomainCombiner

`DomainCombiner` was used to dynamically update
 `ProtectionDomain`s for access control operations and decisions. This
 feature no longer exists.

> *Since 1.3*

> **⚠ Deprecated** — This class was only useful in conjunction with `SecurityManager the Security Manager`, which is no longer supported. There is no replacement for the Security Manager or this class.
