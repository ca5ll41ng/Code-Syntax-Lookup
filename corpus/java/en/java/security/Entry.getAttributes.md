# Entry.getAttributes

```java
default Set<Attribute> getAttributes()
```

Retrieves the attributes associated with an entry.

 The default implementation returns an empty `Set`.

**返回**

- an unmodifiable `Set` of attributes, possibly empty

> *Since 1.8*
