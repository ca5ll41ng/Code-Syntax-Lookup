# Timestamp.hashCode

```java
public int hashCode()
```

Returns the hash code value for this `Timestamp`.
 The hash code is generated using the date and time of the
 `Timestamp` and the TSA's certificate path.

**返回**

- a hash code value for this `Timestamp`.
