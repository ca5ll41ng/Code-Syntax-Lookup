# SecureRandom.getAlgorithm

```java
public String getAlgorithm()
```

Returns the name of the algorithm implemented by this
 `SecureRandom` object.

**返回**

- the name of the algorithm or `unknown` if the algorithm name cannot be determined.

> *Since 1.5*
