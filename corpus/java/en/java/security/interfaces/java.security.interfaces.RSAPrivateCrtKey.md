# RSAPrivateCrtKey

The interface to an RSA private key, as defined in the
 PKCS#1 v2.2 standard,
 using the Chinese Remainder Theorem (CRT) information values.

      RFC 8017: PKCS #1: RSA Cryptography Specifications Version 2.2
