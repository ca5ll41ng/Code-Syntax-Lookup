# AccessControlException

This exception was originally thrown by the `AccessController` to
 indicate that a requested access was denied.

> *Since 1.2*

> **⚠ Deprecated** — This exception was only useful in conjunction with `SecurityManager the Security Manager`, which is no longer supported. There is no replacement for the Security Manager or this class.
