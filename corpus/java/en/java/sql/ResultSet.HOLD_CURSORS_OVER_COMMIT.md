# ResultSet.HOLD_CURSORS_OVER_COMMIT

```java
int HOLD_CURSORS_OVER_COMMIT = 1
```

The constant indicating that open `ResultSet` objects with this
 holdability will remain open when the current transaction is committed.

> *Since 1.4*
