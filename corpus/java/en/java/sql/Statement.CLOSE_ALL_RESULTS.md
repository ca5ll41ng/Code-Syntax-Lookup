# Statement.CLOSE_ALL_RESULTS

```java
int CLOSE_ALL_RESULTS = 3
```

The constant indicating that all `ResultSet` objects that
 have previously been kept open should be closed when calling
 `getMoreResults`.

> *Since 1.4*
