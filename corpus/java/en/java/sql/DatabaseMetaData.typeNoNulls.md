# DatabaseMetaData.typeNoNulls

```java
int typeNoNulls = 0
```

Indicates that a `NULL` value is NOT allowed for this
 data type.
 

 A possible value for column `NULLABLE` in the
 `ResultSet` object returned by the method
 `getTypeInfo`.
