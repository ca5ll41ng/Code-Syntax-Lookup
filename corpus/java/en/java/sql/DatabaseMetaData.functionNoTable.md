# DatabaseMetaData.functionNoTable

```java
int functionNoTable = 1
```

Indicates that the function  does not return a table.
 

 A possible value for column `FUNCTION_TYPE` in the
 `ResultSet` object returned by the method
 `getFunctions`.

> *Since 1.6*
