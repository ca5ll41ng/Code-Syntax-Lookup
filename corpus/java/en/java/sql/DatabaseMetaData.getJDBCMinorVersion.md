# DatabaseMetaData.getJDBCMinorVersion

```java
int getJDBCMinorVersion() throws SQLException
```

Retrieves the minor JDBC version number for this
 driver.

**返回**

- JDBC version minor number

**异常**

- **SQLException** — if a database access error occurs

> *Since 1.4*
