# DatabaseMetaData.isReadOnly

```java
boolean isReadOnly() throws SQLException
```

Retrieves whether this database is in read-only mode.

**返回**

- `true` if so; `false` otherwise

**异常**

- **SQLException** — if a database access error occurs
