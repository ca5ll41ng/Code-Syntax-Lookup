# DatabaseMetaData.columnNoNulls

```java
int columnNoNulls = 0
```

Indicates that the column might not allow `NULL` values.
 

 A possible value for the column
 `NULLABLE`
 in the `ResultSet` returned by the method
 `getColumns`.
