# DatabaseMetaData.typePredNone

```java
int typePredNone = 0
```

Indicates that `WHERE` search clauses are not supported
 for this type.
 

 A possible value for column `SEARCHABLE` in the
 `ResultSet` object returned by the method
 `getTypeInfo`.
