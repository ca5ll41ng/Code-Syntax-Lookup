# DatabaseMetaData.functionNoNulls

```java
int functionNoNulls = 0
```

Indicates that `NULL` values are not allowed.
 

 A possible value for the column
 `NULLABLE`
 in the `ResultSet` object
 returned by the method `getFunctionColumns`.

> *Since 1.6*
