# SQLTransactionRollbackException.SQLTransactionRollbackException

```java
public SQLTransactionRollbackException()
```

Constructs a `SQLTransactionRollbackException` object.
 The `reason`, `SQLState` are initialized
 to `null` and the vendor code is initialized to 0.

 The `cause` is not initialized, and may subsequently be
 initialized by a call to the
 `initCause` method.

> *Since 1.6*
