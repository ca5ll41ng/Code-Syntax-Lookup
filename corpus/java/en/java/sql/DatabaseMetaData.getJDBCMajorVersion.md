# DatabaseMetaData.getJDBCMajorVersion

```java
int getJDBCMajorVersion() throws SQLException
```

Retrieves the major JDBC version number for this
 driver.

**返回**

- JDBC version major number

**异常**

- **SQLException** — if a database access error occurs

> *Since 1.4*
