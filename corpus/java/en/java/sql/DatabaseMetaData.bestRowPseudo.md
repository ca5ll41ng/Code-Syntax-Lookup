# DatabaseMetaData.bestRowPseudo

```java
int bestRowPseudo = 2
```

Indicates that the best row identifier is a pseudo column.
 

 A possible value for the column
 `PSEUDO_COLUMN`
 in the `ResultSet` object
 returned by the method `getBestRowIdentifier`.
