# ResultSet.CLOSE_CURSORS_AT_COMMIT

```java
int CLOSE_CURSORS_AT_COMMIT = 2
```

The constant indicating that open `ResultSet` objects with this
 holdability will be closed when the current transaction is committed.

> *Since 1.4*
