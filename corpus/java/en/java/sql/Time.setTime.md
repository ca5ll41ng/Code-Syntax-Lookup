# Time.setTime

```java
public void setTime(long time)
```

Sets a `Time` object using a milliseconds time value.

**参数**

- **time** — milliseconds since January 1, 1970, 00:00:00 GMT; a negative number is milliseconds before January 1, 1970, 00:00:00 GMT
