# Statement.setFetchDirection

```java
void setFetchDirection(int direction) throws SQLException
```

Gives the driver a hint as to the direction in which
 rows will be processed in `ResultSet`
 objects created using this `Statement` object.  The
 default value is `ResultSet.FETCH_FORWARD`.
 

 Note that this method sets the default fetch direction for
 result sets generated by this `Statement` object.
 Each result set has its own methods for getting and setting
 its own fetch direction.

**参数**

- **direction** — the initial direction for processing rows

**异常**

- **SQLException** — if a database access error occurs, this method is called on a closed `Statement` or the given direction is not one of `ResultSet.FETCH_FORWARD`, `ResultSet.FETCH_REVERSE`, or `ResultSet.FETCH_UNKNOWN`
