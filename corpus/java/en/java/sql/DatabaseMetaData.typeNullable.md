# DatabaseMetaData.typeNullable

```java
int typeNullable = 1
```

Indicates that a `NULL` value is allowed for this
 data type.
 

 A possible value for column `NULLABLE` in the
 `ResultSet` object returned by the method
 `getTypeInfo`.
