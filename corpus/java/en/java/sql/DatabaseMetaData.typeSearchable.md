# DatabaseMetaData.typeSearchable

```java
int typeSearchable = 3
```

Indicates that all `WHERE` search clauses can be
 based on this type.
 

 A possible value for column `SEARCHABLE` in the
 `ResultSet` object returned by the method
 `getTypeInfo`.
