# DatabaseMetaData.functionColumnInOut

```java
int functionColumnInOut = 2
```

Indicates that the parameter or column is an INOUT parameter.
 

 A possible value for the column
 `COLUMN_TYPE`
 in the `ResultSet`
 returned by the method `getFunctionColumns`.
