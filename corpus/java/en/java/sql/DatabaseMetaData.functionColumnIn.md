# DatabaseMetaData.functionColumnIn

```java
int functionColumnIn = 1
```

Indicates that the parameter or column is an IN parameter.
 

  A possible value for the column
 `COLUMN_TYPE`
 in the `ResultSet`
 returned by the method `getFunctionColumns`.

> *Since 1.6*
