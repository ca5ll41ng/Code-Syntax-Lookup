# DatabaseMetaData.columnNullableUnknown

```java
int columnNullableUnknown = 2
```

Indicates that the nullability of columns is unknown.
 

 A possible value for the column
 `NULLABLE`
 in the `ResultSet` returned by the method
 `getColumns`.
