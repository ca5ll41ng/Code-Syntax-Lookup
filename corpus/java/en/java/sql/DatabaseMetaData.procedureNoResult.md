# DatabaseMetaData.procedureNoResult

```java
int procedureNoResult = 1
```

Indicates that the procedure does not return a result.
 

 A possible value for column `PROCEDURE_TYPE` in the
 `ResultSet` object returned by the method
 `getProcedures`.
