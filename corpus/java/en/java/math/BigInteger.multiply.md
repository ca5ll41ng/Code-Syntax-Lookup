# BigInteger.multiply

```java
public BigInteger multiply(BigInteger val)
```

Returns a BigInteger whose value is `(this * val)`.

 performance when `val == this`.

**参数**

- **val** — value to be multiplied by this BigInteger.

**返回**

- `this * val`
