# RMISecurityException

An RMISecurityException signals that a security exception
 has occurred during the execution of one of
 java.rmi.RMISecurityManager's methods.

> *Since 1.1*

> **⚠ Deprecated** — Use `java.lang.SecurityException` instead. Application code should never directly reference this class, and RMISecurityManager no longer throws this subclass of java.lang.SecurityException.
