# CoderMalfunctionError

Error thrown when the `decodeLoop decodeLoop` method of
 a `CharsetDecoder`, or the `encodeLoop
 encodeLoop` method of a `CharsetEncoder`, throws an unexpected
 exception.

> *Since 1.4*
