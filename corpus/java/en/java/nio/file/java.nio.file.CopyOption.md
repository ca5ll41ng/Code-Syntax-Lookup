# CopyOption

An object that configures how to copy or move a file.

 

 Objects of this type may be used with the `copy`,
 `copy(java.io.InputStream,Path,CopyOption[])
 Files.copy` and `move
 Files.move` methods to configure how a file is
 copied or moved.

 

 The `StandardCopyOption` enumeration type defines the
 standard options.

> *Since 1.7*
