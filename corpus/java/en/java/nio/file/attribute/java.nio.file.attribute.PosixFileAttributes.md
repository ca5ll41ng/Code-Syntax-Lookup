# PosixFileAttributes

File attributes associated with files on file systems used by operating systems
 that implement the Portable Operating System Interface (POSIX) family of
 standards.

 

 The POSIX attributes of a file are retrieved using a `PosixFileAttributeView` by invoking its `readAttributes readAttributes` method.

> *Since 1.7*
