# FileAttribute

An object that encapsulates the value of a file attribute that can be set
 atomically when creating a new file or directory by invoking the `createFile createFile` or `createDirectory createDirectory` methods.

**参数**

- **The** — type of the file attribute value

**参见**

- PosixFilePermissions#asFileAttribute

> *Since 1.7*
