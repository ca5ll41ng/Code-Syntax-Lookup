# Math.addExact

```java
public static int addExact(int x, int y)
```

Returns the sum of its arguments,
 throwing an exception if the result overflows an `int`.

**参数**

- **x** — the first value
- **y** — the second value

**返回**

- the result

**异常**

- **ArithmeticException** — if the result overflows an int

> *Since 1.8*
