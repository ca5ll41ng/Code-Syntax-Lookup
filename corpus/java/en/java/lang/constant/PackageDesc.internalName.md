# PackageDesc.internalName

```java
String internalName()
```

Returns the fully qualified (slash-separated) package name in internal form
 of this `PackageDesc`.

**返回**

- the package name in internal form, or the empty string for the unnamed package

**参见**

- PackageDesc#name()
