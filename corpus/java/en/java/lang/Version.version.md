# Version.version

```java
public List<Integer> version()
```

Returns an unmodifiable `java.util.List List` of the integers
 represented in the version number.
 The `List` always contains at least one element corresponding to
 the feature version number.

**返回**

- An unmodifiable list of the integers represented in the version number
