# Thread.checkAccess

```java
public final void checkAccess()
```

Does nothing.

> **⚠ Deprecated** — This method originally determined if the currently running thread had permission to modify this thread. This method was only useful in conjunction with `SecurityManager the Security Manager`, which is no longer supported. There is no replacement for the Security Manager or this method.
