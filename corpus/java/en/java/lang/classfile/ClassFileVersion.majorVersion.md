# ClassFileVersion.majorVersion

```java
int majorVersion()
```

{@return the major version}  It is a `#u2 u2`
 value.

 Constants in `ClassFile` named `Java_#_VERSION`, where # is
 a release number, such as `JAVA_21_VERSION`, describe the
 class major versions of the Java Platform SE.
