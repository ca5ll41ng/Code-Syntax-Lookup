# ClassFile.MAGIC_NUMBER

```java
int MAGIC_NUMBER = 0xCAFEBABE
```

The magic number identifying the `class` file format,  `"0x%04x" #MAGIC_NUMBER`.  It is a big-endian 4-byte value.
