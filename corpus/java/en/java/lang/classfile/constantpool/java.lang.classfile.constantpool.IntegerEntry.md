# IntegerEntry

Models a `CONSTANT_Integer_info` structure, or an `int` constant,
 in the constant pool of a `class` file.
 

 The use of a `IntegerEntry` is modeled by an `int`.  Conversions
 are through `intEntry` and `intValue`.
