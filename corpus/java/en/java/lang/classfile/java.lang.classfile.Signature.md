# Signature

Models generic Java type signatures, as defined in JVMS {@jvms 4.7.9.1}.
 

 Names in signatures are identifiers, which must
 not be empty and must not contain any of the ASCII characters `. ; [ / < > :`.  Top-level class and interface names are denoted by
 slash-separated identifiers.
