# String.isEmpty

```java
public boolean isEmpty()
```

Returns `true` if, and only if, `length` is `0`.

 To determine whether a string contains only
 `isWhitespace(int) white space`, use
 `isBlank() isBlank`.

**返回**

- `true` if `length` is `0`, otherwise `false`

> *Since 1.6*
