# ConstantGroup.subGroup

```java
default ConstantGroup subGroup(int start, int end)
```

Create a view on a sub-sequence of this group.

**参数**

- **start** — the index to begin the view
- **end** — the index to end the view

**返回**

- a view on the selected sub-group
