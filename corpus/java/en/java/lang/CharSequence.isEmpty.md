# CharSequence.isEmpty

```java
default boolean isEmpty()
```

Returns `true` if this character sequence is empty.

 The default implementation returns the result of calling `length() == 0`.

**返回**

- `true` if `length` is `0`, otherwise `false`

> *Since 15*
