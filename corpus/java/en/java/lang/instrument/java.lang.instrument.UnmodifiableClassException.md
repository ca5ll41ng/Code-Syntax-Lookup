# UnmodifiableClassException

Thrown by an implementation of
 `redefineClasses Instrumentation.redefineClasses`
 when one of the specified classes cannot be modified.

**参见**

- java.lang.instrument.Instrumentation#redefineClasses

> *Since 1.5*
