# String.resolveConstantDesc

```java
public String resolveConstantDesc(MethodHandles.Lookup lookup)
```

Resolves this instance as a `ConstantDesc`, the result of which is
 the instance itself.

**参数**

- **lookup** — ignored

**返回**

- the `String` instance

> *Since 12*
