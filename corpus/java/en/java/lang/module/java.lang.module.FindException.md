# FindException

Thrown by a `ModuleFinder ModuleFinder` when an error occurs finding
 a module. Also thrown by `resolve(ModuleFinder,java.util.List,ModuleFinder,java.util.Collection)
 Configuration.resolve` when resolution fails for observability-related
 reasons.

> *Since 9*
