# Math.multiplyHigh

```java
public static long multiplyHigh(long x, long y)
```

Returns as a `long` the most significant 64 bits of the 128-bit
 product of two 64-bit factors.

**参数**

- **x** — the first value
- **y** — the second value

**返回**

- the result

- #unsignedMultiplyHigh
