# ClassLoader.getPlatformClassLoader

```java
public static ClassLoader getPlatformClassLoader()
```

Returns the platform class loader.  All
 platform classes are visible to
 the platform class loader.

 `"platform"`.

**返回**

- The platform `ClassLoader`.

> *Since 9*
