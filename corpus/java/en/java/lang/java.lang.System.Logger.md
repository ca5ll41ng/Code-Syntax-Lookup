# Logger

`System.Logger` instances log messages that will be
 routed to the underlying logging framework the `System.LoggerFinder
 LoggerFinder` uses.

 `System.Logger` instances are typically obtained from
 the `java.lang.System System` class, by calling
 `getLogger`
 or `getLogger(java.lang.String, java.util.ResourceBundle)
 System.getLogger`.

**参见**

- java.lang.System#getLogger(java.lang.String)
- java.lang.System#getLogger(java.lang.String, java.util.ResourceBundle)
- java.lang.System.LoggerFinder

> *Since 9*
