# Math.unsignedMultiplyHigh

```java
public static long unsignedMultiplyHigh(long x, long y)
```

Returns as a `long` the most significant 64 bits of the unsigned
 128-bit product of two unsigned 64-bit factors.

**参数**

- **x** — the first value
- **y** — the second value

**返回**

- the result
