# String.contains

```java
public boolean contains(CharSequence s)
```

Returns true if and only if this string contains the specified
 sequence of char values.

**参数**

- **s** — the sequence to search for

**返回**

- true if this string contains `s`, false otherwise

> *Since 1.5*
