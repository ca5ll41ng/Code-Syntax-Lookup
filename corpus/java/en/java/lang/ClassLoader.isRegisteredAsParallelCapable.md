# ClassLoader.isRegisteredAsParallelCapable

```java
public final boolean isRegisteredAsParallelCapable()
```

Returns `true` if this class loader is registered as
 `registerAsParallelCapable parallel capable`, otherwise
 `false`.

**返回**

- `true` if this class loader is parallel capable, otherwise `false`.

**参见**

- #registerAsParallelCapable()

> *Since 9*
