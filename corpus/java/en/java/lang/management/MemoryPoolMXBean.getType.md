# MemoryPoolMXBean.getType

```java
public MemoryType getType()
```

Returns the type of this memory pool.

 

 **MBeanServer access**:

 The mapped type of `MemoryType` is `String`
 and the value is the name of the `MemoryType`.

**返回**

- the type of this memory pool.
