# CompilationMXBean.isCompilationTimeMonitoringSupported

```java
public boolean isCompilationTimeMonitoringSupported()
```

Tests if the Java virtual machine supports the monitoring of
 compilation time.

**返回**

- `true` if the monitoring of compilation time is supported; `false` otherwise.
