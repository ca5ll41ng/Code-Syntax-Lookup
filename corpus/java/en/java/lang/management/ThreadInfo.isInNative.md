# ThreadInfo.isInNative

```java
public boolean isInNative()
```

Tests if the thread associated with this `ThreadInfo` is executing
 native code.

 

 A thread is considered to be executing native code when it is executing a
 native method, executing native code invoked using a `downcallHandle(java.lang.foreign.FunctionDescriptor, Linker.Option...)
 method handle` obtained from the `Linker native linker`, or is
 
 attached to the VM with the 
 Java Native Interface with no Java frames on its stack.

 

 Native code does not include Java virtual machine support code,
 compiled code generated by the Java virtual machine, or special cases
 such as a thread blocked on a 
 JVM TI raw monitor.

**返回**

- `true` if the thread is executing native code; `false` otherwise.
