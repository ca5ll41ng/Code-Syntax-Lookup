# Type

A ListFormat type - `STANDARD STANDARD`, `OR OR`, and
 `UNIT UNIT`.
 

 `Type` is an enum which represents the type for formatting
 a list within a given `ListFormat` instance. It determines
 the punctuation and the connecting words in the formatted text.
