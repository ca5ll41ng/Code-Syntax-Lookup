# NumericPosition.setPositiveSuffix

```java
public void setPositiveSuffix (String newValue)
```

Set the positive suffix.
 

Example: 123%

**参数**

- **newValue** — the new positive suffix. Non-null.

**异常**

- **NullPointerException** — if `newValue` is `null`
