# DateFormatSymbols.setWeekdays

```java
public void setWeekdays(String[] newWeekdays)
```

Sets weekday strings. For example: "Sunday", "Monday", etc.

**参数**

- **newWeekdays** — the new weekday strings. The array should be indexed by `SUNDAY Calendar.SUNDAY`, `MONDAY Calendar.MONDAY`, etc.
