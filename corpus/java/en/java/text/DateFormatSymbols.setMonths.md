# DateFormatSymbols.setMonths

```java
public void setMonths(String[] newMonths)
```

Sets month strings. For example: "January", "February", etc.

**参数**

- **newMonths** — the new month strings. The array should be indexed by `JANUARY Calendar.JANUARY`, `FEBRUARY Calendar.FEBRUARY`, etc.
