# DecimalFormatSymbols.setNaN

```java
public void setNaN(String NaN)
```

Sets the string used to represent "not a number". Almost always left
 unchanged.

**参数**

- **NaN** — the string representing "not a number"

**异常**

- **NullPointerException** — if `NaN` is `null`
