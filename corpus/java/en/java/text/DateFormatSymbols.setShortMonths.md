# DateFormatSymbols.setShortMonths

```java
public void setShortMonths(String[] newShortMonths)
```

Sets short month strings. For example: "Jan", "Feb", etc.

**参数**

- **newShortMonths** — the new short month strings. The array should be indexed by `JANUARY Calendar.JANUARY`, `FEBRUARY Calendar.FEBRUARY`, etc.
