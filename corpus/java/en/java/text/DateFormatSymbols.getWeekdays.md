# DateFormatSymbols.getWeekdays

```java
public String[] getWeekdays()
```

Gets weekday strings. For example: "Sunday", "Monday", etc.

**返回**

- the weekday strings. Use `SUNDAY Calendar.SUNDAY`, `MONDAY Calendar.MONDAY`, etc. to index the result array.
