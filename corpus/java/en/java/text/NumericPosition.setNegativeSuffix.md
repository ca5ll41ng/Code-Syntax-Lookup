# NumericPosition.setNegativeSuffix

```java
public void setNegativeSuffix (String newValue)
```

Set the negative suffix.
 

Examples: 123%

**参数**

- **newValue** — the new negative suffix. Non-null.

**异常**

- **NullPointerException** — if `newValue` is `null`
