# Month.getValue

```java
public int getValue()
```

Gets the month-of-year `int` value.
 

 The values are numbered following the ISO-8601 standard,
 from 1 (January) to 12 (December).

**返回**

- the month-of-year, from 1 (January) to 12 (December)
