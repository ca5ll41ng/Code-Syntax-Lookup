# DayOfWeek.getValue

```java
public int getValue()
```

Gets the day-of-week `int` value.
 

 The values are numbered following the ISO-8601 standard, from 1 (Monday) to 7 (Sunday).
 See `dayOfWeek` for localized week-numbering.

**返回**

- the day-of-week, from 1 (Monday) to 7 (Sunday)
