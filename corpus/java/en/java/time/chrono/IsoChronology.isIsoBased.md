# IsoChronology.isIsoBased

```java
public boolean isIsoBased()
```

`IsoChronology` is an ISO based chronology, which supports fields
 in `IsoFields`, such as `DAY_OF_QUARTER DAY_OF_QUARTER`
 and `QUARTER_OF_YEAR QUARTER_OF_YEAR`.

**返回**

- `true`
