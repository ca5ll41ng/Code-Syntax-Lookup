# ThaiBuddhistEra.getValue

```java
public int getValue()
```

Gets the numeric era `int` value.
 

 The era BEFORE_BE has the value 0, while the era BE has the value 1.

**返回**

- the era value, from 0 (BEFORE_BE) to 1 (BE)
