# MinguoEra.getValue

```java
public int getValue()
```

Gets the numeric era `int` value.
 

 The era BEFORE_ROC has the value 0, while the era ROC has the value 1.

**返回**

- the era value, from 0 (BEFORE_ROC) to 1 (ROC)
