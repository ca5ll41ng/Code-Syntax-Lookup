# ZoneRulesProvider.getAvailableZoneIds

```java
public static Set<String> getAvailableZoneIds()
```

Gets the set of available zone IDs.
 

 These IDs are the string form of a `ZoneId`.

**返回**

- the unmodifiable set of zone IDs, not null
