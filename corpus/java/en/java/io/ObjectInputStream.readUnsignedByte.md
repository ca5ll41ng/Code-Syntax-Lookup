# ObjectInputStream.readUnsignedByte

```java
public int readUnsignedByte() throws IOException
```

Reads an unsigned 8-bit byte.

**返回**

- the 8-bit byte read.

**异常**

- **EOFException** — If end of file is reached.
- **IOException** — If other I/O error has occurred.
