# ObjectInput.skip

```java
public long skip(long n) throws IOException
```

Skips n bytes of input.

**参数**

- **n** — the number of bytes to be skipped

**返回**

- the actual number of bytes skipped.

**异常**

- **IOException** — If an I/O error has occurred.
