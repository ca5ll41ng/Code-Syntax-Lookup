# ObjectInputStream.readLong

```java
public long readLong() throws IOException
```

Reads a 64-bit long.

**返回**

- the read 64-bit long.

**异常**

- **EOFException** — If end of file is reached.
- **IOException** — If other I/O error has occurred.
