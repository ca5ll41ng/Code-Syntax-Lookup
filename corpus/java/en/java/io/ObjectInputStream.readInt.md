# ObjectInputStream.readInt

```java
public int readInt() throws IOException
```

Reads a 32-bit int.

**返回**

- the 32-bit integer read.

**异常**

- **EOFException** — If end of file is reached.
- **IOException** — If other I/O error has occurred.
