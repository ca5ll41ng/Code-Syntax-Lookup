# ObjectInputStream.readDouble

```java
public double readDouble() throws IOException
```

Reads a 64-bit double.

**返回**

- the 64-bit double read.

**异常**

- **EOFException** — If end of file is reached.
- **IOException** — If other I/O error has occurred.
