# ObjectInputStream.readChar

```java
public char readChar() throws IOException
```

Reads a 16-bit char.

**返回**

- the 16-bit char read.

**异常**

- **EOFException** — If end of file is reached.
- **IOException** — If other I/O error has occurred.
