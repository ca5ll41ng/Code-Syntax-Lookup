# ByteArrayInputStream.markSupported

```java
public boolean markSupported()
```

Tests if this `InputStream` supports mark/reset.
 The `markSupported` method of `ByteArrayInputStream`
 always returns `true`.

**返回**

- true

> *Since 1.1*
