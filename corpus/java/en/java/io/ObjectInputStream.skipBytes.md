# ObjectInputStream.skipBytes

```java
public int skipBytes(int len) throws IOException
```

Skips bytes.

**参数**

- **len** — the number of bytes to be skipped

**返回**

- the actual number of bytes skipped.

**异常**

- **IOException** — If an I/O error has occurred.
