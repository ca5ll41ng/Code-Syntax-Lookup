# PBEParameterSpec

This class specifies the set of parameters used with password-based
 encryption (PBE), as defined in the
 PKCS #5
 standard.

      RFC 2898: PKCS #5: Password-Based Cryptography Specification Version 2.0

> *Since 1.4*
