# Cipher.toString

```java
public String toString()
```

Returns a `String` representation of this `Cipher` object.

 This implementation returns a `String` containing the
 transformation, mode, and provider of this `Cipher` object.
 The exact format of the `String` is unspecified and is subject
 to change.

**返回**

- a String describing this `Cipher` object
