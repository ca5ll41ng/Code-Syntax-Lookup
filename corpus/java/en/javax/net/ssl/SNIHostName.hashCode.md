# SNIHostName.hashCode

```java
public int hashCode()
```

Returns a hash code value for this `SNIHostName`.
 

 The hash code value is generated using the case-insensitive hostname
 of this `SNIHostName`.

**返回**

- a hash code value for this `SNIHostName`.
