# HandshakeCompletedListener.handshakeCompleted

```java
void handshakeCompleted(HandshakeCompletedEvent event)
```

This method is invoked on registered objects
 when a SSL handshake is completed.

**参数**

- **event** — the event identifying when the SSL Handshake completed on a given SSL connection
