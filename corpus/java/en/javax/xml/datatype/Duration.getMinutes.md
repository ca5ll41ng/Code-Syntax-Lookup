# Duration.getMinutes

```java
public int getMinutes()
```

Obtains the value of the MINUTES field as an integer value,
 or 0 if not present.

 This method works just like `getYears` except
 that this method works on the MINUTES field.

**返回**

- Minutes of this `Duration`.
