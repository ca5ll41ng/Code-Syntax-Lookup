# XPathFactoryFinder.XPathFactoryFinder

```java
public XPathFactoryFinder(ClassLoader loader)
```

Constructor that specifies ClassLoader to use
 to find XPathFactory.

**参数**

- **loader** — to be used to load resource and `XPathFactory` implementations during the resolution process. If this parameter is null, the default system class loader will be used.
