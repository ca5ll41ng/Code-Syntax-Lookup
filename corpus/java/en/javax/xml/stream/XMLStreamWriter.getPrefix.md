# XMLStreamWriter.getPrefix

```java
public String getPrefix(String uri) throws XMLStreamException
```

Gets the prefix the uri is bound to.

**参数**

- **uri** — the uri the prefix is bound to

**返回**

- the prefix or null

**异常**

- **XMLStreamException** — if an error occurs
