# XMLInputFactory.createXMLStreamReader

```java
public abstract XMLStreamReader createXMLStreamReader(java.io.Reader reader) throws XMLStreamException
```

Create a new XMLStreamReader from a reader.

**参数**

- **reader** — the XML data to read from

**返回**

- an instance of the `XMLStreamReader`

**异常**

- **XMLStreamException** — if an error occurs
