# TextInputCallback

Underlying security services instantiate and pass a
 `TextInputCallback` to the `handle`
 method of a `CallbackHandler` to retrieve generic text
 information.

**参见**

- javax.security.auth.callback.CallbackHandler

> *Since 1.4*
