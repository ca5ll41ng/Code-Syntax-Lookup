# LanguageCallback

Underlying security services instantiate and pass a
 `LanguageCallback` to the `handle`
 method of a `CallbackHandler` to retrieve the `Locale`
 used for localizing text.

**参见**

- javax.security.auth.callback.CallbackHandler

> *Since 1.4*
