# SubjectDomainCombiner

SubjectDomainCombiner was used to dynamically update ProtectionDomains with
 Principals for access control operations and decisions. This feature no
 longer exists.

> *Since 1.4*

> **⚠ Deprecated** — This class was only useful in conjunction with the Security Manager, which is no longer supported. There is no replacement for the Security Manager or this class.
