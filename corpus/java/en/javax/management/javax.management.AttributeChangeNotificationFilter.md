# AttributeChangeNotificationFilter

This class implements of the `javax.management.NotificationFilter NotificationFilter`
 interface for the `javax.management.AttributeChangeNotification attribute change notification`.
 The filtering is performed on the name of the observed attribute.
 

 It manages a list of enabled attribute names.
 A method allows users to enable/disable as many attribute names as required.

> *Since 1.5*
