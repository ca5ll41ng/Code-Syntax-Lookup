# JMXPrincipal.equals

```java
public boolean equals(Object o)
```

Compares the specified Object with this JMXPrincipal
 for equality.  Returns true if the given object is also a
 JMXPrincipal and the two JMXPrincipals
 have the same name.

**参数**

- **o** — Object to be compared for equality with this JMXPrincipal.

**返回**

- true if the specified Object is equal to this JMXPrincipal.
