# JMXConnectorServerProvider

A provider for creating JMX API connector servers using a given
 protocol.  Instances of this interface are created by `JMXConnectorServerFactory` as part of its `newJMXConnectorServer(JMXServiceURL,Map,MBeanServer)
 newJMXConnectorServer` method.

> *Since 1.5*
