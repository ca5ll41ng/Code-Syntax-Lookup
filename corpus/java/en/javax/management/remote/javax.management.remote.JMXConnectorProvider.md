# JMXConnectorProvider

A provider for creating JMX API connector clients using a given
 protocol.  Instances of this interface are created by `JMXConnectorFactory` as part of its `newJMXConnector(JMXServiceURL, Map)
 newJMXConnector` method.

> *Since 1.5*
