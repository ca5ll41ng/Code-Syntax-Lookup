# OpenMBeanAttributeInfo

Describes an attribute of an open MBean.

 

This interface declares the same methods as the class `javax.management.MBeanAttributeInfo`.  A class implementing this
 interface (typically `OpenMBeanAttributeInfoSupport`) should
 extend `javax.management.MBeanAttributeInfo`.

> *Since 1.5*
