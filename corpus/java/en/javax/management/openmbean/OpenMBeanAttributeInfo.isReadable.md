# OpenMBeanAttributeInfo.isReadable

```java
public boolean isReadable()
```

Returns `true` if the attribute described by this `OpenMBeanAttributeInfo`
 instance is readable, `false` otherwise.

**返回**

- true if the attribute is readable.
