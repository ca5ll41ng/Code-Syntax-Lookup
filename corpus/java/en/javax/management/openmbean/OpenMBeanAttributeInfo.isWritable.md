# OpenMBeanAttributeInfo.isWritable

```java
public boolean isWritable()
```

Returns `true` if the attribute described by this `OpenMBeanAttributeInfo`
 instance is writable, `false` otherwise.

**返回**

- true if the attribute is writable.
