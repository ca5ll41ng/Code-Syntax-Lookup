# OpenMBeanParameterInfoSupport.hasMinValue

```java
public boolean hasMinValue()
```

Returns `true` if this `OpenMBeanParameterInfoSupport` instance specifies a non-null
 minimal value for the described parameter, `false`
 otherwise.
