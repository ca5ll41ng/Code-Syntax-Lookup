# ArrayType.isPrimitiveArray

```java
public boolean isPrimitiveArray()
```

Returns `true` if the open data values this open
 type describes are primitive arrays, `false` otherwise.

**返回**

- true if this is a primitive array type.

> *Since 1.6*
