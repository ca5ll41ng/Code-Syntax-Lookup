# OpenMBeanParameterInfo.isValue

```java
public boolean isValue(Object obj)
```

Tests whether obj is a valid value for the parameter
 described by this `OpenMBeanParameterInfo` instance.

**参数**

- **obj** — the object to be tested.

**返回**

- `true` if obj is a valid value for the parameter described by this `OpenMBeanParameterInfo` instance, `false` otherwise.
