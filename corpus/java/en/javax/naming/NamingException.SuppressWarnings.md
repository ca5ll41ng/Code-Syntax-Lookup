# NamingException.SuppressWarnings

```java
@SuppressWarnings("serial") // Not statically typed as Serializable protected Object resolvedObj
```

Contains the object to which resolution of the part of the name was
 successful. Can be null.
 This field is initialized by the constructors.
 You should access and manipulate this field
 through its get and set methods.
