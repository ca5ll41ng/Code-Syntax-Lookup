# NameClassPair.isRelative

```java
public boolean isRelative()
```

Determines whether the name of this binding is
 relative to the target context (which is named by
 the first parameter of the list() method).

**返回**

- true if the name of this binding is relative to the target context; false if the name of this binding is a URL string.
