# Temporal.PlainDateTime.prototype.yearOfWeek

The **`yearOfWeek`** accessor property of `Temporal.PlainDateTime` instances returns an integer representing the year to be paired with the `Temporal/PlainDateTime/weekOfYear` of this date, or `undefined` if the calendar does not have a well-defined week system. It is [calendar](/en-US/docs/Web/JavaScript/Reference/Global_Objects/Temporal#calendars)-dependent.

The set accessor of `yearOfWeek` is `undefined`. You cannot change this property directly.

For general information and more examples, see `Temporal/PlainDate/yearOfWeek`.
