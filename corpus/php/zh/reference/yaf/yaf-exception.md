# Yaf_Exception 类

Yaf_Exception

   简介  Yaf_Exception 是 Yaf 抛出的所有异常的基类。 其它所有 Yaf 异常类都继承自它。    当加载了 SPL 扩展时，它继承自 RuntimeException，否则继承内置的 Exception。 Yaf 抛出的异常都带有一个用于标识故障类型的错误码。      类摘要   `Yaf_Exception`    `Yaf_Exception`   `extends` `RuntimeException`    继承的属性  方法   继承的方法
