# Yaf_Exception_LoadFailed 类

Yaf_Exception_LoadFailed

   简介  当自动加载器无法加载所需的脚本时， 会抛出 `Yaf_Exception_LoadFailed`。 它的错误码是 `520`。 更具体的失败由它的子类 `Yaf_Exception_LoadFailed_Module`、 `Yaf_Exception_LoadFailed_Controller`、 `Yaf_Exception_LoadFailed_Action` 和 `Yaf_Exception_LoadFailed_View` 表示。      类摘要   `Yaf_Exception_LoadFailed`    `Yaf_Exception_LoadFailed`   `extends` `Yaf_Exception`    属性 方法 继承的方法
