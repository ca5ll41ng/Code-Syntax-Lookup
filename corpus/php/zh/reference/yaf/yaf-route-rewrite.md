# Yaf_Route_Rewrite 类

Yaf_Route_Rewrite

   简介  `Yaf_Route_Rewrite` 是内置路由， 它将固定的路径模式映射到模块（module）、控制器（controller）和动作（action）。 模式中可以包含命名占位符（`:name`，其值会被设置为请求参数）， 以及结尾的 `*` 通配符，用于将剩余的路径段捕获为键/值对。    用法请参考 `Yaf_Route_Rewrite::__construct()` 的示例部分。      类摘要   `Yaf_Route_Rewrite`    `Yaf_Route_Rewrite`   `extends` `Yaf_Route_Interface`   Yaf_Route_Interface    属性  `protected` `_route`   `protected` `_default`   `protected` `_verify`  方法   继承的方法       属性
