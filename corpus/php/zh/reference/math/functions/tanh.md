# 双曲正切

## 说明

```php
float tanh(float $num)
```

返回 `$num` 的双曲正切值，定义为 `sinh($num)/cosh($num)`。

## 参数

- **`$num`** — 要处理的参数

## 返回值

`$num` 的双曲正切值

## 参见

`tan()` `atanh()` `sinh()` `cosh()`
