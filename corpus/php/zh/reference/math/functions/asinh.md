# 反双曲正弦

## 说明

```php
float asinh(float $num)
```

返回 `$num` 的反双曲正弦值，即，其双曲正弦为 `$num` 的那个值。

## 参数

- **`$num`** — 要处理的参数

## 返回值

返回 `$num` 的反双曲正弦

## 参见

`sinh()` `asin()` `acosh()` `atanh()`
