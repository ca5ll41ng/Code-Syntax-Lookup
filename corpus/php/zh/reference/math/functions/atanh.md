# 反双曲正切

## 说明

```php
float atanh(float $num)
```

返回 `$num` 的反双曲正切值，即，其双曲正切为 `$num` 的那个值。

## 参数

- **`$num`** — 要处理的参数

## 返回值

`$num` 的反双曲正切

## 参见

`tanh()` `atan()` `asinh()` `acosh()`
