# 双曲余弦

## 说明

```php
float cosh(float $num)
```

返回 `$num` 的双曲余弦值，定义为 `(exp($num) + exp(-$num))/2`。

## 参数

- **`$num`** — 要处理的参数

## 返回值

`$num` 的双曲余弦值。

## 参见

`cos()` `acosh()` `sinh()` `tanh()`
