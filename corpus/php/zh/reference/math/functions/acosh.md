# 反双曲余弦

## 说明

```php
float acosh(float $num)
```

返回 `$num` 的反双曲余弦值，即其双曲余弦为 `$num` 的那个值。

## 参数

- **`$num`** — 要处理的值

## 返回值

`$num` 反双曲余弦

## 参见

`cosh()` `acos()` `asinh()` `atanh()`
