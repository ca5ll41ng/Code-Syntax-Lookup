# 反正切

## 说明

```php
float atan(float $num)
```

返回 `$num` 的反正切值，单位是弧度。`atan()` 是 `tan()` 的反函数，它的意思是对于 `atan()` 的定义域中的每个 `$num` 值，$num == tan(atan($num))。

## 参数

- **`$num`** — 要处理的参数

## 返回值

`$num` 的反正切弧度。

## 参见

`tan()` `atanh()` `asin()` `acos()`
