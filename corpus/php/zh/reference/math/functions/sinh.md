# 双曲正弦

## 说明

```php
float sinh(float $num)
```

返回 `$num` 的双曲正弦值，定义为 `(exp($num) - exp(-$num))/2`。

## 参数

- **`$num`** — 要处理的参数

## 返回值

`$num` 的双曲正弦值

## 参见

`sin()` `asinh()` `cosh()` `tanh()`
