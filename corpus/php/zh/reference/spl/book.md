# PHP 标准库（SPL）

SPL

 简介  标准 PHP 库（SPL）扩展定义了接口和类，用于解决常见问题。    该扩展提供了各种数据结构、通用异常、迭代器、使用面向对象 API 的文件系统类，以及实用函数。
