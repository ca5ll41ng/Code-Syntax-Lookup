# FTP

{{{ preface 

 简介  本扩展中的函数实现了通过 FTP 协议访问文件服务器的客户端。FTP 协议在 [959](959) 中定义。本扩展提供了对于 FTP 服务器完整的访问及控制功能。如果只是简单的从 FTP 服务器读取或向服务器写入一个文件，请考虑使用 `ftp://` 封装协议 和 文件系统函数， 会更加的简单。
