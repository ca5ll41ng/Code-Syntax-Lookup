# 安装/配置

## 需求

虽然不是必需的，xhprof 包含了一个用 PHP 写的用户界面。 它是一个用来保存分析后的数据、并用浏览器显示的实用办法。 因此一个启用了 PHP 的 web 服务器将使人更能体验到 xhprof 的用处。
