# 预定义常量

下列常量由此扩展定义，且仅在此扩展编译入 PHP 或在运行时动态载入时可用。

- **`XHPROF_FLAGS_NO_BUILTINS` (`int`)** — 使得跳过所有内置（内部）函数。
- **`XHPROF_FLAGS_CPU` (`int`)** — 使输出的性能数据中添加 CPU 数据。
- **`XHPROF_FLAGS_MEMORY` (`int`)** — 使输出的性能数据中添加内存数据。
