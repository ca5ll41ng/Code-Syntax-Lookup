# 安装/配置

{{{ Requirements 

## 需求

要使用 PostgreSQL 支持，你需要 libpq（PostgreSQL C 客户端库）。 从 PHP 8.0.0 开始，需要 libpq 9.1 或更高版本。 从 PHP 8.4.0 开始，需要 libpq 10.0 或更高版本。 PostgreSQL 支持包含多字节字符编码的多种字符编码。有关 PostgreSQL 的当前版本和更多信息，请访问 []() 和 [PostgreSQL 文档]()。
