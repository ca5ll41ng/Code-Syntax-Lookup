# PostgreSQL

{{{ preface 

 简介  PostgreSQL 数据库是开源产品，免费提供。Postgres 最初由加州大学伯克利分校计算机科学系开发，首创了许多对象关系概念，现在可以在一些商业数据库中使用。它提供 SQL92/SQL99 语言支持、事务、参照完整性、存储过程和可扩展类型（type extensibility）。PostgreSQL 是这个原始伯克利代码的开源后代。
