# 预定义常量

下列常量由此扩展定义，且仅在此扩展编译入 PHP 或在运行时动态载入时可用。

- **`HASH_HMAC` (`int`)** — `hash_init()` 中的可选标志。表示 HMAC digest-keying 算法应被用于当前散列上下文环境。
