# 安装/配置

{{{ Installation 

## 安装

Hash 扩展是 PHP 的核心扩展，所以始终启用。

PHP 7.4 之前，Hash 扩展默认在 PHP 中捆绑并编译，但可以通过 --disable-hash 手动禁用。

在 5.1.2 之前，Hash 扩展作为 [PECL 模块](hash) 安装。
