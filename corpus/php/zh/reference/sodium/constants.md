# 预定义常量

下列常量由此扩展定义，且仅在此扩展编译入 PHP 或在运行时动态载入时可用。

- **`SODIUM_LIBRARY_VERSION` (`string`)**
- **`SODIUM_LIBRARY_MAJOR_VERSION` (`int`)**
- **`SODIUM_LIBRARY_MINOR_VERSION` (`int`)**
- **`SODIUM_BASE64_VARIANT_ORIGINAL` (`int`)**
- **`SODIUM_BASE64_VARIANT_ORIGINAL_NO_PADDING` (`int`)**
- **`SODIUM_BASE64_VARIANT_URLSAFE` (`int`)**
- **`SODIUM_BASE64_VARIANT_URLSAFE_NO_PADDING` (`int`)**
- **`SODIUM_CRYPTO_AEAD_AEGIS128L_KEYBYTES` (`int`)** — 自 PHP 8.4.0 起可用。
- **`SODIUM_CRYPTO_AEAD_AEGIS128L_NSECBYTES` (`int`)** — 自 PHP 8.4.0 起可用。
- **`SODIUM_CRYPTO_AEAD_AEGIS128L_NPUBBYTES` (`int`)** — 自 PHP 8.4.0 起可用。
- **`SODIUM_CRYPTO_AEAD_AEGIS128L_ABYTES` (`int`)** — 自 PHP 8.4.0 起可用。
- **`SODIUM_CRYPTO_AEAD_AEGIS256_KEYBYTES` (`int`)** — 自 PHP 8.4.0 起可用。
- **`SODIUM_CRYPTO_AEAD_AEGIS256_NSECBYTES` (`int`)** — 自 PHP 8.4.0 起可用。
- **`SODIUM_CRYPTO_AEAD_AEGIS256_NPUBBYTES` (`int`)** — 自 PHP 8.4.0 起可用。
- **`SODIUM_CRYPTO_AEAD_AEGIS256_ABYTES` (`int`)** — 自 PHP 8.4.0 起可用。
- **`SODIUM_CRYPTO_AEAD_AES256GCM_KEYBYTES` (`int`)** — 仅在编译时包含 AES-256-GCM 支持的平台上定义。 自 PHP 8.4.0 起在 aarch64 上定义。
- **`SODIUM_CRYPTO_AEAD_AES256GCM_NSECBYTES` (`int`)** — 仅在编译时包含 AES-256-GCM 支持的平台上定义。 自 PHP 8.4.0 起在 aarch64 上定义。
- **`SODIUM_CRYPTO_AEAD_AES256GCM_NPUBBYTES` (`int`)** — 仅在编译时包含 AES-256-GCM 支持的平台上定义。 自 PHP 8.4.0 起在 aarch64 上定义。
- **`SODIUM_CRYPTO_AEAD_AES256GCM_ABYTES` (`int`)** — 仅在编译时包含 AES-256-GCM 支持的平台上定义。 自 PHP 8.4.0 起在 aarch64 上定义。
