# Tokenizer

Tokenizer

 简介  tokenizer 函数为嵌入在 Zend 引擎中的 PHP tokenizer 提供了接口。使用这些函数，可以编写自己的 PHP 源代码分析或修改工具，而无需在词法级别处理语言规范。    参阅记号附录。
