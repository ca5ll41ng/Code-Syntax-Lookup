# 预定义常量

下列常量由此扩展定义，且仅在此扩展编译入 PHP 或在运行时动态载入时可用。

- **`EXIF_USE_MBSTRING` (`int`)** — 如果启用了 mbstring，这个常量的值为 `1`， 否则为 `0`。

`exif_imagetype()` 列出几个相关的内建变量。
