# Geo IP 定位

GeoIP

 简介  GeoIP 扩展可以通过 IP 地址来确定地理位置。比如城市、州、国家、经度、纬度以及其他信息，比如 ISP (因特网服务提供商)和网络连接类型。   
> 该扩展不支持 MaxMind 目前的 “GeoIP2” 数据库。 只有 “GeoIP 遗留” 数据库文件。
