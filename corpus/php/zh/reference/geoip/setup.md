# 安装/配置

## 需求

这个扩展要求系统安装了 GeoIP C 语言库的1.4.0及以上版本。可通过以下链接 []() 下载编译该库。

默认情况下只能使用免费的 GeoIP Country 或者 GeoLite City 的数据库。然而这个模块可以使用其他类型的数据库，但必须从以下链接购买商业许可 [Maxmind]()。

## 安装

此  扩展未与 PHP 捆绑。

安装此 PECL 扩展相关的信息可在手册中标题为 PECL 扩展的安装章节中找到。更多信息如新的发行版本、下载、源文件、 维护人员信息及变更日志等，都在此处： [geoip](geoip).
