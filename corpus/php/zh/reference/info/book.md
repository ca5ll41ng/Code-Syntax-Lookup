# PHP 选项和信息

PHP 选项/信息

 简介  这些函数允许你获得许多关于PHP本身的参数，例如：运行时的配置，被加载的扩展，版本等。 你也将找到设置你的运行中的PHP的选项的函数。可能最好用的 PHP- 函数 `phpinfo()` 可以在这里找到。
