# Oracle OCI8

OCI8

 {{{ preface 

 简介 
> 自 PHP 8.4.0 起，此扩展不再*捆绑*。

  这些函数允许访问 Oracle 数据库。支持 SQL 和 PL/SQL 语句。基本功能包括对事务控制、PHP 变量与 Oracle 占位符的绑定以及大对象（LOB）类型和集合的支持。还支持 Oracle 的可伸缩性特性，例如数据库驻留连接池（DRCP）和结果缓存。   

 }}}
