# 获取网络中每一层的偏差数

## 说明

```php
array fann_get_bias_array(resource $ann)
```

获取网络中每一层的偏差数。

## 参数

- **`$ann`** — 神经网络 `资源`。

## 返回值

包含每一层偏差数的数组。
