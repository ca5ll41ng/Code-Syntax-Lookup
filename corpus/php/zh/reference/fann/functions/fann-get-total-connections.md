# 获取整个网络中所有的连接数。

## 说明

```php
int fann_get_total_connections(resource $ann)
```

获取整个网络中所有的连接数。

## 参数

- **`$ann`** — 神经网络 `资源`。

## 返回值

成功，则返回整个网络中所有的连接数, 错误则返回 `false` .
