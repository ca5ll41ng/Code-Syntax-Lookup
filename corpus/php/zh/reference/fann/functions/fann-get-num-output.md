# 获取输出神经元的数量。

## 说明

```php
int fann_get_num_output(resource $ann)
```

获取输出神经元的数量。

## 参数

- **`$ann`** — 神经网络 `资源`。

## 返回值

成功，则返回输出神经元的数量, 错误则返回 `false` .
