# FANN (快速人工神经网络)

FANN

 简介  PHP绑定了 FANN (快速人工神经网络) 库，该库实现了多层人工神经网络从而为全连接网络和稀疏连接网络提供支持。 该库是一个让训练数据集变得简单的框架。上手时快速，简单，文档也很丰富。
