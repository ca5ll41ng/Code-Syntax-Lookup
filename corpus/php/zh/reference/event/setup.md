# 安装/配置

## 需求

此扩展需要 [libevent]() 库。大多数现代发行版都提供了 libevent 包。

OpenSSL 功能需要 [OpenSSL]() 库。

## 安装

此  扩展未与 PHP 捆绑。

安装此 PECL 扩展相关的信息可在手册中标题为 PECL 扩展的安装章节中找到。更多信息如新的发行版本、下载、源文件、 维护人员信息及变更日志等，都在此处： [event](event)。
