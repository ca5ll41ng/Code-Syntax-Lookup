# 从儒略日数转换为法国共和历

## 说明

```php
string jdtofrench(int $julian_day)
```

从儒略日数转换为法国共和历。

## 参数

- **`$julian_day`** — int 类型的儒略日数

## 返回值

string 类型，“月/日/年”格式的法国共和历日期

## 参见

`frenchtojd()` `cal_from_jd()`
