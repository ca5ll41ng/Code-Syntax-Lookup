# 安装

安装此 PECL 扩展相关的信息可在手册中标题为 PECL 扩展的安装章节中找到。更多信息如新的发行版本、下载、源文件、 维护人员信息及变更日志等，都在此处： [cubrid](cubrid).

PECL 扩展的 DLL 当前不可用。参见 在 Windows 上构建章节。

关于在 Linux 和 Windows 系统上的安装手册信息，请阅读包含在包中的这个文件`build-guide.html`。
