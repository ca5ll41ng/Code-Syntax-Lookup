# 获取底层 rrdtool 库的相关信息

## 说明

```php
string rrd_version()
```

返回底层 rrdtool 的相关信息。

## 参数

此函数没有参数。

## 返回值

rrdtool 版本的字符串版本号。例如：“1.4.3”。
