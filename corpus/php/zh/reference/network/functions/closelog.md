# 关闭系统日志链接

## 说明

```php
true closelog()
```

`closelog()` 关闭用于通信的描述符并写入系统日志。`closelog()`是可选的。

## 参数

此函数没有参数。

## 返回值

总是返回 `true`。

## 参见

`syslog()` `openlog()`
