# 通知 readline 将光标移动到新行

## 说明

```php
void readline_on_new_line()
```

告诉 readline 将光标移动到新行。

## 参数

此函数没有参数。

## 返回值

没有返回值。

## 注释

> 此函数仅在底层 readline 库支持时可用。不支持 Windows。
