# 清除历史

## 说明

```php
true readline_clear_history()
```

这个函数清除全部的命令行历史。

## 参数

此函数没有参数。

## 返回值

总是返回 `true`。

## 更新日志

| 版本 | 说明 |
| --- | --- |
| 8.5.0 | 返回值类型现在是 `true`；之前是 `bool`。 |
