# 安装

要使用这些函数，必须编译支持 readline 的 PHP 的 CGI 或者 CLI 版本。需要配置 PHP --with-readline[=DIR]。如果想使用 libedit 代替 readline，配置 PHP --with-libedit[=DIR]。

在 Windows 上，此扩展自 PHP 7.1.0 起默认可用。
