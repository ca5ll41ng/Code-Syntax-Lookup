# 为图片设置指定的格式

## 说明

```php
public bool Imagick::setImageFormat(string $format)
```

为图片设置指定的格式

## 参数

- **`$format`** — 表示图片格式的一个字符串。支持的格式依赖于 ImageMagick 的安装。

## 返回值

成功时返回 `true`。
