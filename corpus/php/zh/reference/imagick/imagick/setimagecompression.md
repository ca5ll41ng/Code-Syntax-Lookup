# 设置图片压缩的类型

## 说明

```php
public bool Imagick::setImageCompression(int $compression)
```

## 参数

- **`$compression`** — `COMPRESSION` 常量里的一种

## 返回值

成功时返回 `true`。

## 错误／异常

错误时抛出 ImagickException。
