# 获取图像的x,y轴分辨率

## 说明

```php
public array Imagick::getImageResolution()
```

获取图像的x,y轴分辨率

## 参数

此函数没有参数。

## 返回值

返回分辨率值的数组

## 错误／异常

错误时抛出 ImagickException。
