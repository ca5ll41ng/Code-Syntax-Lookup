# 去掉图片的所有配置和设置

## 说明

```php
public bool Imagick::stripImage()
```

去掉图片的所有配置和设置

## 参数

此函数没有参数。

## 返回值

成功时返回 `true`。

## 错误／异常

错误时抛出 ImagickException。
