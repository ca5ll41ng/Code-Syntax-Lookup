# 获取图像的分辨率单位

## 说明

```php
public int Imagick::getImageUnits()
```

获取图像的分辨率单位。

## 参数

此函数没有参数。

## 返回值

返回分辨率的单位

## 错误／异常

错误时抛出 ImagickException。
