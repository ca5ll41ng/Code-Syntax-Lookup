# 安装/配置

{{{ Requirements 

## 需求

需要安装 [libcurl]() 包才能使用 PHP 的 cURL 函数。PHP 需要使用 7.10.5 或更高版本的 libcurl。从 PHP 7.3.0 起，需要 7.15.5 或更高版本。从 PHP 8.0.0 起，需要 7.29.0 或更高版本。自 PHP 8.4.0 起，需要 7.61.0 或更高版本。
