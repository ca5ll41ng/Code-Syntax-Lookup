# 显示随机数最大的可能值

## 说明

```php
int getrandmax()
```

返回调用 `rand()` 可能返回的最大值。

## 参数

此函数没有参数。

## 返回值

`rand()` 返回随机数可能返回的最大值

## 参见

`rand()` `srand()` `mt_getrandmax()`
