# 移除一个必需的参数

## 说明

```php
final public bool OAuthProvider::removeRequiredParameter(string $req_params)
```

移除一个必需的参数。

> 本函数还未编写文档，仅有参数列表。

## 参数

- **`$req_params`** — 要被移除的必需参数。

## 返回值

成功时返回 `true`， 或者在失败时返回 `false`。

## 参见

 `OAuthProvider::setParam()` `OAuthProvider::addRequiredParameter()`
