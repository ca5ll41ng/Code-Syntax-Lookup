# 获取最后一次的响应

## 说明

```php
public string OAuth::getLastResponse()
```

获取最近一次请求的原始响应。

## 参数

此函数没有参数。

## 返回值

返回一个最后一次响应的字符串。

## 参见

 `OAuth::getLastResponseInfo()` `OAuth::fetch()`
