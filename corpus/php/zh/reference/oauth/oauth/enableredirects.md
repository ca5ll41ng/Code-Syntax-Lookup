# 启用重定向

## 说明

```php
public bool OAuth::enableRedirects()
```

启用自动重定向，此项默认为启用。

> 本函数还未编写文档，仅有参数列表。

## 参数

此函数没有参数。

## 返回值

`true`

## 参见

 `OAuth::disableRedirects()`
