# 安装/配置

## 需求

该扩展要求 [libmemcached]() 客户端库（版本 1.0.0 或更高）。对于 SASL 身份验证支持，libmemcached 必须在启用 SASL 的情况下编译。

自版本 0.2.0 起，此扩展需要 PHP 版本 5.2.0 或更高版本。
