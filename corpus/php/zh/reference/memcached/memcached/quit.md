# 关闭所有打开的链接

## 说明

```php
public bool Memcached::quit()
```

`Memcached::quit()` 关闭所有 memcache 服务器的链接。

## 参数

此函数没有参数。

## 返回值

成功时返回 `true`， 或者在失败时返回 `false`。
