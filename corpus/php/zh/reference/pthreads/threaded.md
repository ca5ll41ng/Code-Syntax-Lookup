# Threaded 类

Threaded

   简介  Threaded 对象提供支持 pthreads 操作的基本功能，包括同步方法以及其他对程序员很有帮助的接口。    重要的是，Threaded 提供了隐式的线程安全机制，这个对象中的所有操作都是线程安全的。      类摘要   `Threaded`    `Threaded`   Collectable   Traversable   Countable   ArrayAccess    方法
