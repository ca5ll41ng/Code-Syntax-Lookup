# 改变 Pool 对象的可容纳 Worker 对象的数量

## 说明

```php
public void Pool::resize(int $size)
```

改变 Pool 对象的可容纳 Worker 对象的数量

## 参数

- **`$size`** — 此 Pool 对象可创建 Worker 对象的最大数量

## 返回值

没有返回值。
