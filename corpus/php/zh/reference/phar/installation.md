# 安装

Phar 扩展与 PHP 捆绑且默认启用。禁用 Phar 支持，使用 --disable-phar。

在之前的 PHP 版本，可以通过 PECL 扩展安装 Phar，[Phar PECL 页面](phar)包含了历史以及更多信息。
