# 获取 SeasLog 作者

## 说明

```php
string seaslog_get_author()
```

## 参数

此函数没有参数。

## 返回值

返回一个 SeasLog 作者的字符串

## 示例

**`seaslog_get_author()` 示例**

```php


<?php

var_dump(seaslog_get_author());

?>

   
```

以上示例的输出类似于：

```text


string(29) "Chitao.Gao  [ neeke@php.net ]"

   
```
