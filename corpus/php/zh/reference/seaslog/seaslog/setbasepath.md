# 设置 SeasLog 根目录

## 说明

```php
public static bool SeasLog::setBasePath(string $base_path)
```

设置 SeasLog 根目录。

## 参数

- **`$base_path`** — String.

## 返回值

设置根目录成功返回 TRUE，失败返回 FALSE。
