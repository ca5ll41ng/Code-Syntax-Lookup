# 安装/配置

{{{ Requirements 

## 需求

要使用 Open SSL 函数，你必须安装[OpenSSL]() 库。 PHP 7.0 需要 OpenSSL >= 0.9.8。PHP 7.1-8.0 需要 OpenSSL >= 1.0.1，< 3.0。PHP >= 8.1 支持 OpenSSL >= 1.0.2, < 4.0。 PHP >= 8.4 支持 OpenSSL >= 1.1.1, < 4.0。

> 强烈建议使用维护的 OpenSSL 版本，否则 web 服务器很容易受到攻击。
