# 判断方法是否是抽象方法

## 说明

```php
public bool ReflectionMethod::isAbstract()
```

判断方法是否是抽象方法

## 参数

此函数没有参数。

## 返回值

如果是抽象方法返回 `true`，否则返回 `false`

## 参见

`ReflectionMethod::getDeclaringClass()`
