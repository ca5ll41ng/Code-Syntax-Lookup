# 判断方法是否是 protected

## 说明

```php
public bool ReflectionMethod::isProtected()
```

判断方法是否是 protected。

## 参数

此函数没有参数。

## 返回值

方法是 protected，返回 `true`，否则返回 `false`

## 参见

`ReflectionMethod::isPrivate()`
