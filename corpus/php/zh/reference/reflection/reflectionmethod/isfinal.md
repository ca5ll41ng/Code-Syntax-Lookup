# 判断方法是否定义 final

## 说明

```php
public bool ReflectionMethod::isFinal()
```

判断方法是否定义 final。

## 参数

此函数没有参数。

## 返回值

如果是 final 返回 `true`，否则返回 `false`

## 参见

`ReflectionMethod::isStatic()`
