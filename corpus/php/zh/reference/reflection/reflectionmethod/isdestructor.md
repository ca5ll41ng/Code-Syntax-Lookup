# 判断方法是否是析构方法

## 说明

```php
public bool ReflectionMethod::isDestructor()
```

判断方法是否是析构方法

## 参数

此函数没有参数。

## 返回值

如果是析构方法返回 `true`，否则返回 `false`

## 参见

`ReflectionMethod::isConstructor()`
