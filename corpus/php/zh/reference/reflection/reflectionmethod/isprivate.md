# 判断方法是否是私有

## 说明

```php
public bool ReflectionMethod::isPrivate()
```

判断方法是否是私有。

## 参数

此函数没有参数。

## 返回值

方法私有为 `true`，否则为 `false`。

## 参见

`ReflectionMethod::isPublic()`
