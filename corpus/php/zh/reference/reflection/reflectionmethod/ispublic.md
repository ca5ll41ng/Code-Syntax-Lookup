# 判断方法是否是 public

## 说明

```php
public bool ReflectionMethod::isPublic()
```

判断方法是否是 public。

## 参数

此函数没有参数。

## 返回值

方法是 public，返回 `true`，否则返回 `false`

## 参见

`ReflectionMethod::isPrivate()`
