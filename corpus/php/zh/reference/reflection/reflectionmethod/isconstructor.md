# 判断方法是否是构造方法

## 说明

```php
public bool ReflectionMethod::isConstructor()
```

判断方法是否是构造方法

## 参数

此函数没有参数。

## 返回值

如果是构造方法返回 `true`，否则返回 `false`

## 参见

`ReflectionMethod::__construct()` `ReflectionMethod::isAbstract()` `ReflectionMethod::isDestructor()`
