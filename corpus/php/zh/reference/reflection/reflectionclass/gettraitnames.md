# 返回这个类所使用 traits 的名称的数组

## 说明

```php
public array ReflectionClass::getTraitNames()
```

获取该类使用的 trait 名称。

## 参数

此函数没有参数。

## 返回值

返回的数组的值包含了 trait 的名称。
