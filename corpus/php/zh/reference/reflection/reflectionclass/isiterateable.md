# 别名 `ReflectionClass::isIterable()`

## 说明

别名 `ReflectionClass::isIterable()`

自 PHP 7.2.0 起，应该首选 `RefectionClass::isIterable()`，而不是拼写错误的 `ReflectionClass::isIterateable()`。
