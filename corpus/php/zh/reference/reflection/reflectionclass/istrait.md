# 返回了是否是 trait

## 说明

```php
public bool ReflectionClass::isTrait()
```

检查 `ReflectionClass` 是否指向 trait。

## 参数

此函数没有参数。

## 返回值

如果是 trait 返回 `true`，否则返回 `false`。
