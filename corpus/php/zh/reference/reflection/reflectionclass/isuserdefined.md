# 检查是否由用户定义的

## 说明

```php
public bool ReflectionClass::isUserDefined()
```

检查一个类是否由用户定义，和内置相对。

## 参数

此函数没有参数。

## 返回值

成功时返回 `true`， 或者在失败时返回 `false`。

## 参见

`ReflectionClass::isInternal()`
