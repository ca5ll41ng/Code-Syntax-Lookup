# 获取类的修饰符

## 说明

```php
public int ReflectionClass::getModifiers()
```

返回这个类访问修饰符的位字段。

## 参数

此函数没有参数。

## 返回值

返回 修饰符常量 的位掩码。

## 参见

`ReflectionClass::getProperties()` `Reflection::getModifierNames()`
