# 获取起始行号

## 说明

```php
public int|false ReflectionClass::getStartLine()
```

获取起始的行号。

## 参数

此函数没有参数。

## 返回值

起始的行号，类型是 `int`，如果未知，则为 `false`。

## 参见

`ReflectionClass::getEndLine()`
