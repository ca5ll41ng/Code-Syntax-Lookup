# 获取父类

## 说明

```php
public ReflectionClass|false ReflectionClass::getParentClass()
```

获取父级类。

## 参数

此函数没有参数。

## 返回值

`ReflectionClass`，没有父类为 `false`。

## 参见

`ReflectionClass::__construct()`
