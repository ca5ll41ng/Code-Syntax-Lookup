# 检查是否是用户定义

## 说明

```php
public bool ReflectionFunctionAbstract::isUserDefined()
```

检查函数是否是用户自定义，也就是说不是 PHP 自己内置函数。

## 参数

此函数没有参数。

## 返回值

用户自定义函数返回 `true`，否则返回 `false`

## 参见

`ReflectionFunctionAbstract::isInternal()`
