# 获取注释内容

## 说明

```php
public string|false ReflectionFunctionAbstract::getDocComment()
```

获取函数的文档注释。

## 参数

此函数没有参数。

## 返回值

如果存在文档注释返回其内容，否则返回 `false`。

## 参见

`ReflectionFunctionAbstract::getStartLine()`
