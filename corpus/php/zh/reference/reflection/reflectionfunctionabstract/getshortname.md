# 获取函数短名称

## 说明

```php
public string ReflectionFunctionAbstract::getShortName()
```

获取函数的段名称 (没有命名空间定义)。

## 参数

此函数没有参数。

## 返回值

函数短名称。

## 参见

`ReflectionFunctionAbstract::getNamespaceName()` 命名空间
