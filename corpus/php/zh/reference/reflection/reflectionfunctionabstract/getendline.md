# 获取结束行号

## 说明

```php
public int|false ReflectionFunctionAbstract::getEndLine()
```

获取结束行号。

## 参数

此函数没有参数。

## 返回值

获取用户定义函数的结束行号，如果未知返回 `false`。

## 参见

`ReflectionFunctionAbstract::getStartLine()`
