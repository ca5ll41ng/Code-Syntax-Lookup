# 获取命名空间

## 说明

```php
public string ReflectionFunctionAbstract::getNamespaceName()
```

获取类定义所属的命名空间。

## 参数

此函数没有参数。

## 返回值

返回命名空间。

## 参见

`ReflectionFunctionAbstract::getFileName()` 命名空间
