# 获取参数数目

## 说明

```php
public int ReflectionFunctionAbstract::getNumberOfParameters()
```

获取函数定义的参数数量，包括可选参数。

## 参数

此函数没有参数。

## 返回值

参数的个数。

## 参见

`ReflectionFunctionAbstract::getNumberOfRequiredParameters()` `func_num_args()`
