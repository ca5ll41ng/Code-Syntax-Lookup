# 检查是否处于命名空间

## 说明

```php
public bool ReflectionFunctionAbstract::inNamespace()
```

检查函数是否在命名空间内定义。

## 参数

此函数没有参数。

## 返回值

在命名空间内返回 `true`，否则返回 `false`

## 参见

`ReflectionFunctionAbstract::getNamespaceName()` 命名空间
