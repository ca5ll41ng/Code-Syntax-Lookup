# 检查是否返回引用

## 说明

```php
public bool ReflectionFunctionAbstract::returnsReference()
```

检查是否返回引用

## 参数

此函数没有参数。

## 返回值

如果返回引用则为 `true`，否则为 `false`

## 参见

`ReflectionFunctionAbstract::isClosure()`
