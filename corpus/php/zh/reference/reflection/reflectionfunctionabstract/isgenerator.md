# 判断函数是否是一个生成器函数

## 说明

```php
public bool ReflectionFunctionAbstract::isGenerator()
```

## 参数

此函数没有参数。

## 返回值

生成器函数返回 `true`，不是返回 `false` 失败时返回 `null`。
