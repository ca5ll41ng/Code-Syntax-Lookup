# 判断函数是否是内置函数

## 说明

```php
public bool ReflectionFunctionAbstract::isInternal()
```

判断函数是否是内置函数，而非用户自定义。

## 参数

此函数没有参数。

## 返回值

内置函数返回 `true`，否则返回 `false`

## 参见

`ReflectionFunctionAbstract::isUserDefined()`
