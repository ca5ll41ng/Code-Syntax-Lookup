# 获取扩展名称

## 说明

```php
public string|false ReflectionFunctionAbstract::getExtensionName()
```

获取扩展名称。

## 参数

此函数没有参数。

## 返回值

定义函数的扩展名，用户定义函数则为 `false`。

## 参见

`ReflectionFunctionAbstract::getExtension()`
