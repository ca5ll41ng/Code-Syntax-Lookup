# 获取扩展信息

## 说明

```php
public ReflectionExtension|null ReflectionFunctionAbstract::getExtension()
```

获取函数的扩展信息

## 参数

此函数没有参数。

## 返回值

包含扩展信息的 `ReflectionExtension` 对象，用户定义的函数则为 `null`。

## 参见

`ReflectionFunctionAbstract::getExtensionName()`
