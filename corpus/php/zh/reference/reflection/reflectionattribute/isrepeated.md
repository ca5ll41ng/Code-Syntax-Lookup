# 返回该名称的属性是否已重复出现在代码元素上

## 说明

```php
public bool ReflectionAttribute::isRepeated()
```

返回该名称的属性是否已重复出现在代码元素上。

## 参数

此函数没有参数。

## 返回值

当属性被重复使用时返回 `true`，否则返回 `false`。
