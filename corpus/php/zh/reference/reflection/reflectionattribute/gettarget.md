# 返回属性的目标位掩码

## 说明

```php
public int ReflectionAttribute::getTarget()
```

获取属性的目标位掩码。

## 参数

此函数没有参数。

## 返回值

获取属性的目标作为 `Attribute::TARGET_*` 常量的位掩码。
