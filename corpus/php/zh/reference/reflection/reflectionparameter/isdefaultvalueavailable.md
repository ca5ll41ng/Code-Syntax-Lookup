# 检查默认是否可用

## 说明

```php
public bool ReflectionParameter::isDefaultValueAvailable()
```

检查参数默认值是否可用。

## 参数

此函数没有参数。

## 返回值

如果默认值可用为 `true` 否则为 `false`

`ReflectionParameter::getDefaultValue()` `ReflectionParameter::isDefaultValueConstant()` `ReflectionParameter::getName()`
