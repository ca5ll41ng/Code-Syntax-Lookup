# PropertyHookType 枚举

PropertyHookType

  简介  `PropertyHookType` 枚举列出了属性挂钩的合法类型。     注解摘要  `PropertyHookType`  Get 'get'  表示 `get` 挂钩。    Set 'set'  表示 `set` 挂钩。
