# Zlib 压缩

Zlib

 {{{ preface 

 简介  该模块能够无障碍地读写 gzip 压缩过的文件，使用大多数 filesystem 函数的版本，与 gzip 压缩文件（以及未压缩的文件，但不能与 socket 一起使用）一起使用。   
> PHP 还有用于 `.gz` 文件的 fopen 封装协议。有关 `wrappers.compression` 的部分提供了更多信息。
