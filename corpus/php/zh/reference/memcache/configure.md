# 安装

此  扩展未与 PHP 捆绑。 安装此 PECL 扩展相关的信息可在手册中标题为 PECL 扩展的安装章节中找到。更多信息如新的发行版本、下载、源文件、 维护人员信息及变更日志等，都在此处： [memcache](memcache).

> 可以禁用 memcache session 处理程序的支持。“pecl install”选项对此进行提示（默认启用），但是当静态编译为 PHP 时，可以使用 --disable-memcache-session 配置选项。
