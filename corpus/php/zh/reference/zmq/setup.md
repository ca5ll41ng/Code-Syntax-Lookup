# 安装/配置

## 需求

ZMQ 扩展需要 0MQ 2.0.7 及以上版本。0MQ 可以这里获取 [area:download](area:download)。

## 安装

此扩展被认为已无人维护及已消亡。然而，此扩展的源代码还可在 PECL SVN 找到： [zmq](zmq)

此扩展在 Windows 平台的二进制扩展 (DLL 文件) PECL 可以在 PECL 官方网站上下载。
