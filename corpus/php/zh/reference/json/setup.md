# 安装/配置

## 需求

使用这些函数不需要安装，它们是 PHP 核心的一部分。

## 安装

JSON 扩展是 PHP 核心扩展，所以始终启用。

PHP 8.0.0 之前，JSON 扩展默认捆绑并编译到 PHP 中，但可以使用 --disable-json 手动禁用。
