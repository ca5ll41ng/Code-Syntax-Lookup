# JsonException 类

JsonException

   简介  如果为 `json_encode()` 或 `json_decode()` 设置了 JSON_THROW_ON_ERROR 选项，则会抛出异常。 `code` 包含错误类型，关于可能的值请参见 `json_last_error()`。      类摘要    JsonException   `extends` `Exception`  继承的属性  继承的方法
