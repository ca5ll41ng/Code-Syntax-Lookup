# 类/对象的信息

类/对象

 简介  这些函数允许你获得类和对象实例的相关信息。 你可以获取对象所属的类名，也可以是它的成员属性和方法。 通过使用这些函数，你不仅可以找到对象和类的关系，也可以是它们的继承关系（例如，对象类继承自哪个类）。    请参见手册中对象一节来查看在 PHP 里，对象和类如何实现和使用的详细描述。
