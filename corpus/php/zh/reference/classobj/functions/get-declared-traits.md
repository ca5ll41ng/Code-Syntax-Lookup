# 返回所有已定义的 traits 的数组

## 说明

```php
array get_declared_traits()
```

## 参数

此函数没有参数。

## 返回值

返回一个数组，其值包含了所有已定义的 traits 的名称。

## 参见

`class_uses()` `trait_exists()`
