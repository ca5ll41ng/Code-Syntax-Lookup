# 类与对象

## 简介

PHP 具有完整的对象模型。特性包括： 访问控制，抽象类和 final 类与方法，附加的魔术方法，接口，对象复制。

PHP 对待对象的方式等同于引用或句柄，即每个变量都持有对象的引用，而不是整个对象的复制。参见 对象和引用。
