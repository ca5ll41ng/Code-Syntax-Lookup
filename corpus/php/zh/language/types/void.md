# Void

`void` 是仅用于返回类型，表示函数不返回值，但该函数仍可能会终止。因此，它不能成为联合类型声明的一部分。自 PHP 7.1.0 起可用。

> 即使函数的返回类型是 `void`，但仍然可以返回值，但值只能始终为 `null`。
