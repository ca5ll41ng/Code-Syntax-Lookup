# Mixed

`mixed` 类型接受每个值。等同于联合类型 `object|resource|array|string|float|int|bool|null`。自 PHP 8.0.0 起可用。

在类型理论中，`mixed` 是顶级类型。这意味着其它所有类型都是它的子类型。
