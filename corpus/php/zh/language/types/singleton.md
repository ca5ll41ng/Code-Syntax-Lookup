# 单例类型

单例类型（singleton type）是只允许单个值的类型。PHP 支持两种单例类型：`false`（自 PHP 8.0.0 起支持），`true`（自 PHP 8.2.0 起支持）。

> 在 PHP 8.2.0 之前，`false` 类型只能用作联合类型的一部分。

> 无法定义自定义单例类型。建议改用枚举。
