# 返回到迭代器的第一个元素

## 说明

```php
public void Iterator::rewind()
```

返回到迭代器的第一个元素。

> 当开始一个  循环时，这是*第一个*被调用的方法。它将*不*会在  循环*之后*被调用。

## 参数

此函数没有参数。

## 返回值

任何返回都将被忽略。
