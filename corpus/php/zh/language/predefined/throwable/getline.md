# 获取初始化对象时候的行号

## 说明

```php
public int Throwable::getLine()
```

返回初始化 throwable 时的行号。

## 参数

此函数没有参数。

## 返回值

返回初始化 throwable 时的行号。

## 参见

`Exception::getLine()`
