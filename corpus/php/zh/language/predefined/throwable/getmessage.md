# 获取信息

## 说明

```php
public string Throwable::getMessage()
```

返回抛出对象所关联的描述信息。

## 参数

此函数没有参数。

## 返回值

返回抛出对象所关联的描述信息。

## 参见

`Exception::getMessage()`
