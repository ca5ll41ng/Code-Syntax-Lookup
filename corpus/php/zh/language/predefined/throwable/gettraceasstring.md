# 以 string 形式获取堆栈踪迹

## 说明

```php
public string Throwable::getTraceAsString()
```

## 参数

此函数没有参数。

## 返回值

返回 string 形式的堆栈踪迹（Stack Trace）。

## 参见

`Exception::getTraceAsString()`
