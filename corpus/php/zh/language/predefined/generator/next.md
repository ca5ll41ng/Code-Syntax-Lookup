# 生成器继续执行

## 说明

```php
public void Generator::next()
```

调用 `Generator::next()` 与以 `null` 作为参数调用 `Generator::send()` 具有同样的效果。

## 参数

此函数没有参数。

## 返回值

没有返回值。
