# ParseError

ParseError

   简介  `ParseError` 当解析 PHP 代码时发生错误时抛出，比如当 `eval()`被调用出错时。   
> 从 PHP 7.3.0 开始，`ParseError` 继承自 `CompileError`。之前的版本，则继承自 `Error`。

    类摘要    ParseError   `extends` `CompileError`  继承的属性  继承的方法
