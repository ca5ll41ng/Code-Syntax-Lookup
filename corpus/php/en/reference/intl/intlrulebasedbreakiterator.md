# The IntlRuleBasedBreakIterator class

IntlRuleBasedBreakIterator

   Introduction  A subclass of `IntlBreakIterator` that encapsulates ICU break iterators whose behavior is specified using a set of rules. This is the most common kind of break iterators.    These rules are described in the [ICU Boundary Analysis User Guide]().      Class Synopsis    `IntlRuleBasedBreakIterator`   `extends` `IntlBreakIterator`
