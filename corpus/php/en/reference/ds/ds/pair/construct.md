# Creates a new instance

## Description

```php
public Ds\Pair::__construct([mixed $key = ...], [mixed $value = ...])
```

Creates a new instance using a given `$key` and `$value`.

## Parameters

- **`$key`** — The key.
- **`$value`** — The value.
