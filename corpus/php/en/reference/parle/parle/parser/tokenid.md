# Get token id

## Description

```php
public int Parle\Parser::tokenId(string $tok)
```

Retrieve the id of the named token.

## Parameters

- **`$tok`** — Name of the token as used in `Parle\Parser::token()`.

## Return Values

Returns `integer` representing the token id.
