# Getting Started

## Requirements

XLSWriter requires PHP 7.0 and above.

## Installation

Information for installing this PECL extension may be found in the manual chapter titled Installation of PECL extensions. Additional information such as new releases, downloads, source files, maintainer information, and a CHANGELOG, can be located here: [xlswriter](xlswriter)

## Resource Types

There is one resource used by the procedural version of the XLSWriter extension: returned by `fileName()` or `\Vtiful\Kernel\Format`.
