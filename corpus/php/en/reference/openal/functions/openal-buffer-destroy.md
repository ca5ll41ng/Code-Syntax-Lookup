# Destroys an OpenAL buffer

## Description

```php
bool openal_buffer_destroy(resource $buffer)
```

## Parameters

- **`$buffer`** — An Open AL(Buffer) resource (previously created by `openal_buffer_create()`).

## Return Values

Returns `true` on success or `false` on failure.
