# Destroy a source resource

## Description

```php
bool openal_source_destroy(resource $source)
```

## Parameters

- **`$source`** — An Open AL(Source) resource (previously created by `openal_source_create()`).

## Return Values

Returns `true` on success or `false` on failure.
