# ssdeep Fuzzy Hashing

ssdeep

 Introduction  ssdeep is a utility for creating and comparing fuzzy hashes or [context-triggered piecewise hashing]().    Fuzzy hashing can match signatures which have "...sequences of identical bytes in the same order, although bytes in between these sequences may be different in both content and length" ([ssdeep project page]()).    This extension provides functions for creating and comparing fuzzy hashes.
