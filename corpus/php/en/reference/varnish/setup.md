# Getting Started

## Requirements

To use this extension, a version of Varnish Cache greater than or equal to 3.0 is required to be installed, which is available on the [Varnish Cache homepage]().

## Installation

This  extension is not bundled with PHP.

Information for installing this PECL extension may be found in the manual chapter titled Installation of PECL extensions. Additional information such as new releases, downloads, source files, maintainer information, and a CHANGELOG, can be located here: [varnish](varnish).
