# The EventException class

EventException

   Introduction  A `EventException` is thrown when the Event extension methods encounter invalid user input or identify an unrecoverable error. This exception serves as a signal for developers to handle exceptional situations gracefully.      Class Synopsis    EventException   `extends` `RuntimeException`
