# Returns the request command(method)

## Description

```php
public void EventHttpRequest::getCommand()
```

Returns the request command, one of `EventHttpRequest::CMD_*` constants.

## Parameters

This function has no parameters.

## Return Values

Returns the request command, one of `EventHttpRequest::CMD_*` constants.
