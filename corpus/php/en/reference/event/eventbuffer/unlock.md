# Releases lock acquired by EventBuffer::lock

## Description

```php
public bool EventBuffer::unlock()
```

Releases lock acquired by `EventBuffer::lock()`.

## Parameters

This function has no parameters.

## Return Values

Returns `true` on success or `false` on failure.
