# Append data to the end of an event buffer

## Description

```php
public bool EventBuffer::add(string $data)
```

Append data to the end of an event buffer.

## Parameters

- **`$data`** — String to be appended to the end of the buffer.

## Return Values

Returns `true` on success or `false` on failure.
