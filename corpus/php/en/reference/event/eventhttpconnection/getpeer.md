# Gets the remote address and port associated with the connection

## Description

```php
public void EventHttpConnection::getPeer(string $address, int $port)
```

Gets the remote address and port associated with the connection

## Parameters

- **`$address`** — Address of the peer.
- **`$port`** — Port of the peer.

## Return Values

No value is returned.
