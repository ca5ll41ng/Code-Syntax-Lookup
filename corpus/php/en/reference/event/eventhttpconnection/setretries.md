# Sets the retry limit for the connection

## Description

```php
public void EventHttpConnection::setRetries(int $retries)
```

Sets the retry limit for the connection

## Parameters

- **`$retries`** — The retry limit. `-1` means infinity.

## Return Values

No value is returned.
