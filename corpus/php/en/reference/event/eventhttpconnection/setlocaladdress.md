# Sets the IP address from which HTTP connections are made

## Description

```php
public void EventHttpConnection::setLocalAddress(string $address)
```

Sets the IP address from which http connections are made.

## Parameters

- **`$address`** — The IP address from which HTTP connections are made.

## Return Values

No value is returned.
