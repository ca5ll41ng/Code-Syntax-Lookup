# Sets maximum header size

## Description

```php
public void EventHttpConnection::setMaxHeadersSize(string $max_size)
```

Sets maximum header size for the connection.

## Parameters

- **`$max_size`** — The maximum header size in bytes.

## Return Values

No value is returned.
