# The GearmanClient class

GearmanClient

   Introduction  Represents a class for connecting to a Gearman job server and making requests to perform some function on provided data. The function performed must be one registered by a Gearman worker and the data passed is opaque to the job server.      Class Synopsis    `GearmanClient`
