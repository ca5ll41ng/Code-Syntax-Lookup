# Create a copy of a `GearmanClient` object

## Description

```php
public GearmanClient GearmanClient::clone()
```

Creates a copy of a `GearmanClient` object.

## Parameters

This function has no parameters.

## Return Values

A `GearmanClient` on success, `false` on failure.
