# Set socket I/O activity timeout

## Description

```php
public bool GearmanClient::setTimeout(int $timeout)
```

Sets the timeout for socket I/O activity.

## Parameters

- **`$timeout`** — An interval of time in milliseconds

## Return Values

Always returns `true`.
