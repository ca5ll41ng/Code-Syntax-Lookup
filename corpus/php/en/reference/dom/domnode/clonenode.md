# Clones a node

## Description

```php
public DOMNode|false DOMNode::cloneNode(bool $deep = false)
```

Creates a copy of the node.

## Parameters

- **`$deep`** — Indicates whether to copy all descendant nodes. This parameter is defaulted to `false`.

## Return Values

The cloned node.
