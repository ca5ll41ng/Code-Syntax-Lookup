# The Dom\ParentNode interface

Dom\ParentNode

  Introduction  This is the modern, spec-compliant equivalent of `DOMParentNode`.        Dom\ParentNode    `public` `readonly` `Dom\HTMLCollection` `children`       Properties 
- **`children`** — A `Dom\HTMLCollection` containing all child elements of this node. Available as of PHP 8.5.0.
