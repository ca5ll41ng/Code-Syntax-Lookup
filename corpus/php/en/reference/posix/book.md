# POSIX

{{{ preface 

 Introduction  This module contains an interface to those functions defined in the IEEE 1003.1 (POSIX.1) standards document which are not accessible through other means.   
> Sensitive data can be retrieved with the POSIX functions, e.g. `posix_getpwnam()` and friends.

 
> This extension is not available on Windows platforms.
