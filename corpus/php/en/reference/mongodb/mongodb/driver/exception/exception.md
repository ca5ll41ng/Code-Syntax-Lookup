# The MongoDB\Driver\Exception\Exception interface

MongoDB\Driver\Exception\Exception

   Introduction  Common interface for all extension exceptions. This interface is also used by the library, and may be used to identify any exceptions originating from the MongoDB PHP driver (i.e. extension and library).
