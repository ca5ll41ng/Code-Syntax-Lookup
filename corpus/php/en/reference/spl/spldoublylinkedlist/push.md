# Pushes an element at the end of the doubly linked list

## Description

```php
public void SplDoublyLinkedList::push(mixed $value)
```

Pushes `$value` at the end of the doubly linked list.

## Parameters

- **`$value`** — The value to push.

## Return Values

No value is returned.
