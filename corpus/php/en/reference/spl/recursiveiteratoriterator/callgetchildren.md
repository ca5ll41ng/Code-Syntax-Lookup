# Get children

## Description

```php
public RecursiveIterator|null RecursiveIteratorIterator::callGetChildren()
```

Get children of the current element.

## Parameters

This function has no parameters.

## Return Values

A `RecursiveIterator()` on success, or `null` on failure.
