# Get the handling flags

## Description

```php
public int FilesystemIterator::getFlags()
```

Gets the handling flags, as set in `FilesystemIterator::__construct()` or `FilesystemIterator::setFlags()`.

## Parameters

This function has no parameters.

## Return Values

The integer value of the set flags.

`FilesystemIterator::__construct()` `FilesystemIterator::setFlags()`
