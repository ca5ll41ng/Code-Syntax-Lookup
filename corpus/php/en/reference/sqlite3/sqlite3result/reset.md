# Resets the result set back to the first row

## Description

```php
public bool SQLite3Result::reset()
```

Resets the result set back to the first row.

## Parameters

This function has no parameters.

## Return Values

Returns `true` if the result set is successfully reset back to the first row, `false` on failure.
