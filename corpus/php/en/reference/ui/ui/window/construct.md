# Construct a new Window

## Description

```php
public UI\Window::__construct(string $title, Size $size, bool $menu = false)
```

Shall construct a new Window

## Parameters

- **`$title`** — The title of the Window
- **`$size`** — The size of the Window
- **`$menu`** — Menu switch
