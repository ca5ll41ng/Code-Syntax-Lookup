# Draw a Rectangle

## Description

```php
public UI\Draw\Path::addRectangle(UI\Point $point, UI\Size $size)
```

Shall map the path of a rectangle of the given size, at the given point

## Parameters

- **`$point`** — The point to begin the shape
- **`$size`** — The size of the rectangle
