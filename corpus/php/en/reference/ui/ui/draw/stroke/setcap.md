# Set Line Cap

## Description

```php
public UI\Draw\Stroke::setCap(int $cap)
```

Shall set the line cap setting for this Stroke

## Parameters

- **`$cap`** — UI\Draw\Line\Cap::Flat, UI\Draw\Line\Cap::Round, or UI\Draw\Line\Cap::Square
