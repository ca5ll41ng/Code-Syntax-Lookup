# Set Line Join

## Description

```php
public UI\Draw\Stroke::setJoin(int $join)
```

Shall set the line join setting for this Stroke

## Parameters

- **`$join`** — UI\Draw\Line\Join::Miter, UI\Draw\Line\Join::Round, or UI\Draw\Line\Join::Bevel
