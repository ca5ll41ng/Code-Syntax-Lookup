# Get Line Join

## Description

```php
public int UI\Draw\Stroke::getJoin()
```

Shall retrieve the line join setting of this Stroke

## Parameters

This function has no parameters.

## Return Values

UI\Draw\Line\Join::Miter, UI\Draw\Line\Join::Round, or UI\Draw\Line\Join::Bevel
