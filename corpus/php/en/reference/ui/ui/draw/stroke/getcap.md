# Get Line Cap

## Description

```php
public int UI\Draw\Stroke::getCap()
```

Shall retrieve the line cap setting of this Stroke

## Parameters

This function has no parameters.

## Return Values

UI\Draw\Line\Cap::Flat, UI\Draw\Line\Cap::Round, or UI\Draw\Line\Cap::Square
