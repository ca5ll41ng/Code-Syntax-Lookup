# Draw Text at Point

## Description

```php
public UI\Draw\Pen::write(UI\Point $point, UI\Draw\Text\Layout $layout)
```

Shall draw the given text layout at the given point

## Parameters

- **`$point`** — The point to perform the drawing
- **`$layout`** — The layout of the text to draw
