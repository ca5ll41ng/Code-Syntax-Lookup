# Insert Page

## Description

```php
public UI\Controls\Tab::insertAt(string $name, int $page, UI\Control $control)
```

Shall insert a new page into this Tab

## Parameters

- **`$name`** — The name for the new page
- **`$page`** — The index to perform the insertion before
- **`$control`** — The control for the new page
