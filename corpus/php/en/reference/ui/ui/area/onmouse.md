# Mouse Callback

## Description

```php
protected UI\Area::onMouse(UI\Point $areaPoint, UI\Size $areaSize, int $flags)
```

Shall be executed on mouse events

## Parameters

- **`$areaPoint`** — The co-ordinates of the event
- **`$areaSize`** — The size of the area of the event
- **`$flags`** — Event modifiers
