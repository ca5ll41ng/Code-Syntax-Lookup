# Enter UI Loop

## Description

```php
void UI\run([int $flags = ...])
```

Shall cause PHP to enter into the main loop, by default control will not be returned to the caller

## Parameters

- **`$flags`** — Set UI\Loop to return control, and UI\Wait to return control after waiting
