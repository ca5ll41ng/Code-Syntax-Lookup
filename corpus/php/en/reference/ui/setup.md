# Getting Started

## Requirements

Installation requires the libui library, and PHP 7 or newer.

This extension requires the [libui library]() version 0.1.0 or higher to be installed. See the libui documentation for a list of prerequisites.

## Installation

This  extension is not bundled with PHP.

Information for installing this PECL extension may be found in the manual chapter titled Installation of PECL extensions. Additional information such as new releases, downloads, source files, maintainer information, and a CHANGELOG, can be located here: [ui](ui).

Windows binaries (DLL files) for this PECL extension are available from the PECL website.
