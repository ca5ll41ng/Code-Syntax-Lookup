# Connect to an external name dictionary

## Description

```php
public bool Gender\Gender::connect(string $dsn)
```

Connect to an external name dictionary. Currently only streams are supported.

## Parameters

- **`$dsn`** — DSN to open.

## Return Values

Boolean as success of failure.
