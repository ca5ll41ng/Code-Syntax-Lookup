# Getting Started

## Requirements

`libev` library is embedded into this extension. You don't need to install it separately.

## Installation

This  extension is not bundled with PHP.

Information for installing this PECL extension may be found in the manual chapter titled Installation of PECL extensions. Additional information such as new releases, downloads, source files, maintainer information, and a CHANGELOG, can be located here: [ev](ev).
