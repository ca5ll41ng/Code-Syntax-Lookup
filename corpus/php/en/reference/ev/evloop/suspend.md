# Suspend the loop

## Description

```php
public void EvLoop::suspend()
```

`EvLoop::suspend()` and `EvLoop::resume()` methods suspend and resume a loop correspondingly.

## Parameters

This function has no parameters.

## Return Values

No value is returned.
