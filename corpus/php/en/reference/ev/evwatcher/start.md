# Starts the watcher

## Description

```php
public void EvWatcher::start()
```

Marks the watcher as active. Note that only active watchers will receive events.

## Parameters

This function has no parameters.

## Return Values

No value is returned.

## See Also

  `EvWatcher::stop()`
