# Returns the loop responsible for the watcher

## Description

```php
public EvLoop EvWatcher::getLoop()
```

Returns the loop responsible for the watcher

## Parameters

This function has no parameters.

## Return Values

Returns `EvLoop` event loop object responsible for the watcher.
