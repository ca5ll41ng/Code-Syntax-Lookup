# Invokes the watcher callback with the given received events bit mask

## Description

```php
public void EvWatcher::invoke(int $revents)
```

Invokes the watcher callback with the given received events bit mask.

## Parameters

- **`$revents`** — Bit mask of watcher received events.

## Return Values

No value is returned.
