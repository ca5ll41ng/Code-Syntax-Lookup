# Configures the watcher

## Description

```php
public void EvIo::set(mixed $fd, int $events)
```

Configures the EvIo watcher

## Parameters

- **`$fd`** — The same as for `EvIo::__construct()`
- **`$events`** — The same as for `EvIo::__construct()`

## Return Values

No value is returned.
