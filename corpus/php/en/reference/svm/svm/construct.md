# Construct a new SVM object

## Description

```php
public SVM::__construct()
```

Constructs a new SVM object ready to accept training data.

## Parameters

This function has no parameters.

## Errors/Exceptions

Throws a `SVMException` if the libsvm library could not be loaded.
