# Checks whether a property is lazy

## Description

```php
public bool ReflectionProperty::isLazy(object $object)
```

Checks whether a property is lazy.

## Parameters

- **`$object`** — The object to check the property on.

## Return Values

Returns `true` if the property is lazy, `false` otherwise.
