# Checks whether the property is protected for writing

## Description

```php
public bool ReflectionProperty::isProtectedSet()
```

Checks whether the property is protected for writing.

## Parameters

This function has no parameters.

## Return Values

`true` if the property is `protected(set)`, `false` otherwise.
