# Determines if a property is abstract

## Description

```php
public bool ReflectionProperty::isAbstract()
```

Determines if a property is abstract.

## Parameters

This function has no parameters.

## Return Values

Returns `true` if the property is marked `abstract`, `false` otherwise.
