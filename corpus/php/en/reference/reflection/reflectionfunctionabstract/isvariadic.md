# Checks if the function is variadic

## Description

```php
public bool ReflectionFunctionAbstract::isVariadic()
```

Checks if the function is variadic.

## Parameters

This function has no parameters.

## Return Values

Returns `true` if the function is variadic, otherwise `false`.
