# The SyncSharedMemory class

SyncSharedMemory

   Introduction  A cross-platform, native, consistent implementation of named shared memory objects.    Shared memory lets two separate processes communicate without the need for complex pipes or sockets. There are several integer-based shared memory implementations for PHP. Named shared memory is an alternative.    Synchronization objects (e.g. SyncMutex) are still required to protect most uses of shared memory.
