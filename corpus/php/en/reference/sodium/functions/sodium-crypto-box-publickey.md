# Extract the public key from a crypto_box keypair

## Description

```php
string sodium_crypto_box_publickey(string $key_pair)
```

Given a keypair, fetch only the public key.

## Parameters

- **`$key_pair`** — A keypair, such as one generated by `sodium_crypto_box_keypair()` or `sodium_crypto_box_seed_keypair()`

## Return Values

X25519 public key.
