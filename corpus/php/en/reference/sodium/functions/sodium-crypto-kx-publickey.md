# Extract the public key from a crypto_kx keypair

## Description

```php
string sodium_crypto_kx_publickey(string $key_pair)
```

Extract the public key from a crypto_kx keypair.

## Parameters

- **`$key_pair`** — X25519 keypair, such as one generated by `sodium_crypto_kx_keypair()`.

## Return Values

X25519 public key.
