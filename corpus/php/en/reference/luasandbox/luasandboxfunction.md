# The LuaSandboxFunction class

LuaSandboxFunction

   Introduction  Represents a Lua function, allowing it to be called from PHP.    A LuaSandboxFunction may be obtained as a return value from Lua, as a parameter passed to a callback from Lua, or by using `LuaSandbox::wrapPhpFunction()`, `LuaSandbox::loadString()`, or `LuaSandbox::loadBinary()`.
