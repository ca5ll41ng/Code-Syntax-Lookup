# Indicates if specified property has been set

## Description

```php
public bool XMLReader::getParserProperty(int $property)
```

Indicates if specified property has been set.

## Parameters

- **`$property`** — One of the parser option constants.

## Return Values

Returns `true` on success or `false` on failure.
