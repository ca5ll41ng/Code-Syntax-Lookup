# Generates a single random deviate from a t-distribution

## Description

```php
float stats_rand_gen_t(float $df)
```

Returns a random deviate from the t-distribution with the degrees of freedom, `$df`.

## Parameters

- **`$df`** — The degrees of freedom

## Return Values

A random deviate
