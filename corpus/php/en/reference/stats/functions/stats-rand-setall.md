# Set seed values to the random generator

## Description

```php
void stats_rand_setall(int $iseed1, int $iseed2)
```

Set `$iseed1` and `$iseed2` as seed values to the random generator used in statistic functions.

## Parameters

- **`$iseed1`** — The value which is used as the random seed
- **`$iseed2`** — The value which is used as the random seed

## Return Values

No values are returned.
