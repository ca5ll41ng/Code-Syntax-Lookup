# Returns the percentile value

## Description

```php
float stats_stat_percentile(array $arr, float $perc)
```

Returns the `$perc`-th percentile value of the array `$arr`.

## Parameters

- **`$arr`** — The input array
- **`$perc`** — The percentile

## Return Values

Returns the percentile values of the input array.
