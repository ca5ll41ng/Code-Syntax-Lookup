# Computes the covariance of two data sets

## Description

```php
float stats_covariance(array $a, array $b)
```

Returns the covariance of `$a` and `$b`.

## Parameters

- **`$a`** — The first array
- **`$b`** — The second array

## Return Values

Returns the covariance of `$a` and `$b`, or `false` on failure.
