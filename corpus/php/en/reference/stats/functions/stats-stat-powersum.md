# Returns the power sum of a vector

## Description

```php
float stats_stat_powersum(array $arr, float $power)
```

Returns the sum of the `$power`-th power of a vector represented as an array `$arr`.

## Parameters

- **`$arr`** — The input array
- **`$power`** — The power

## Return Values

Returns the power sum of the input array.
