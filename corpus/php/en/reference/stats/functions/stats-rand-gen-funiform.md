# Generates uniform float between low (exclusive) and high (exclusive)

## Description

```php
float stats_rand_gen_funiform(float $low, float $high)
```

Returns a random deviate from the uniform distribution from `$low` to `$high`.

## Parameters

- **`$low`** — The lower bound (exclusive)
- **`$high`** — The upper bound (exclusive)

## Return Values

A random deviate
