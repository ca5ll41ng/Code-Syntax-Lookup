# Computes the kurtosis of the data in the array

## Description

```php
float stats_kurtosis(array $a)
```

Returns the kurtosis of the values in `$a`.

## Parameters

- **`$a`** — The input array

## Return Values

Returns the kurtosis of the values in `$a`, or `false` if `$a` is empty or is not an array.
