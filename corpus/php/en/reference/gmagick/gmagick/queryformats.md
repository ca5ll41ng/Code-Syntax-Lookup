# Returns formats supported by Gmagick

## Description

```php
public array Gmagick::queryformats(string $pattern = "*")
```

Returns formats supported by `Gmagick`.

## Parameters

- **`$pattern`** — Specifies a `string` containing a pattern.

## Return Values

The `Gmagick` object.

## Errors/Exceptions

Throws an `GmagickException` on error.
