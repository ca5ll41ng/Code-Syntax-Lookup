# Sets the interlace scheme of the image

## Description

```php
public Gmagick Gmagick::setimageinterlacescheme(int $interlace)
```

Sets the interlace scheme of the image.

## Parameters

- **`$interlace`** — One of the Interlace constant (`Gmagick::INTERLACE_*`).

## Return Values

The `Gmagick` object.

## Errors/Exceptions

Throws an `GmagickException` on error.
