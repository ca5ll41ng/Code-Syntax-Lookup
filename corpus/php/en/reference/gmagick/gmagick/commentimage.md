# Adds a comment to your image

## Description

```php
public Gmagick Gmagick::commentimage(string $comment)
```

Adds a comment to your image.

## Parameters

- **`$comment`** — The comment to add.

## Return Values

The `Gmagick` object with comment added.

## Errors/Exceptions

Throws an `GmagickException` on error.
