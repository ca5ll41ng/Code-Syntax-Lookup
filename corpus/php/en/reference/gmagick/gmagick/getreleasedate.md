# Returns the GraphicsMagick release date as a string

## Description

```php
public string Gmagick::getreleasedate()
```

Returns the GraphicsMagick release date as a string.

## Parameters

This function has no parameters.

## Return Values

Returns the GraphicsMagick release date as a string.

## Errors/Exceptions

Throws an `GmagickException` on error.
