# The Gmagick constructor

## Description

```php
public Gmagick::__construct([string $filename = ...])
```

The `Gmagick` constructor.

## Parameters

- **`$filename`** — The path to an image to load or array of paths.

## Errors/Exceptions

Throws an `GmagickException` on error.
