# Gets the image gamma

## Description

```php
public float Gmagick::getimagegamma()
```

Gets the image gamma

## Parameters

This function has no parameters.

## Return Values

Returns the image gamma on success

## Errors/Exceptions

Throws an `GmagickException` on error.
