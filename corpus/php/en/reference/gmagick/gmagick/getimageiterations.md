# Gets the image iterations

## Description

```php
public int Gmagick::getimageiterations()
```

Gets the image iterations.

## Parameters

This function has no parameters.

## Return Values

Returns the image iterations as an integer.

## Errors/Exceptions

Throws an `GmagickException` on error.
