# Sets the filename of a particular image in a sequence

## Description

```php
public Gmagick Gmagick::setimagefilename(string $filename)
```

Sets the filename of a particular image in a sequence.

## Parameters

- **`$filename`** — The image filename.

## Return Values

The `Gmagick` object.

## Errors/Exceptions

Throws an `GmagickException` on error.
