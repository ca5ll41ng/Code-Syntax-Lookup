# Sets the image chromaticity white point

## Description

```php
public Gmagick Gmagick::setimagewhitepoint(float $x, float $y)
```

Sets the image chromaticity white point.

## Parameters

- **`$x`** — The white x-point.
- **`$y`** — The white y-point.

## Return Values

The `Gmagick` object.

## Errors/Exceptions

Throws an `GmagickException` on error.
