# Equalizes the image histogram

## Description

```php
public Gmagick Gmagick::equalizeimage()
```

Equalizes the image histogram.

## Parameters

This function has no parameters.

## Return Values

The equalized `Gmagick` object.

## Errors/Exceptions

Throws an `GmagickException` on error.
