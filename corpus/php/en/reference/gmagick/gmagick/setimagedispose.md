# Sets the image disposal method

## Description

```php
public Gmagick Gmagick::setimagedispose(int $disposeType)
```

Sets the image disposal method.

## Parameters

- **`$disposeType`** — The image disposal type.

## Return Values

The `Gmagick` object.

## Errors/Exceptions

Throws an `GmagickException` on error.
