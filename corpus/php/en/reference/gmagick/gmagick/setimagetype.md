# Sets the image type

## Description

```php
public Gmagick Gmagick::setimagetype(int $imgType)
```

Sets the image type.

## Parameters

- **`$imgType`** — One of the Image type constant (`Gmagick::IMGTYPE_*`).

## Return Values

The `Gmagick` object.

## Errors/Exceptions

Throws an `GmagickException` on error.
