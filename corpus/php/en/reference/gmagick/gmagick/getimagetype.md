# Gets the potential image type

## Description

```php
public int Gmagick::getimagetype()
```

Gets the potential image type.

## Parameters

This function has no parameters.

## Return Values

Returns the potential image type.

## Errors/Exceptions

Throws an `GmagickException` on error.
