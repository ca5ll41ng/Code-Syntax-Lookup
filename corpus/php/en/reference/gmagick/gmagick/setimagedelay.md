# Sets the image delay

## Description

```php
public Gmagick Gmagick::setimagedelay(int $delay)
```

Sets the image delay.

## Parameters

- **`$delay`** — The image delay in 1/100th of a second.

## Return Values

The `Gmagick` object.

## Errors/Exceptions

Throws an `GmagickException` on error.
