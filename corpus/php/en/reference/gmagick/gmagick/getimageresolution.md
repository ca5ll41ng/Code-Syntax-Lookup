# Gets the image X and Y resolution

## Description

```php
public array Gmagick::getimageresolution()
```

Returns the resolution as an array.

## Parameters

This function has no parameters.

## Return Values

Returns the resolution as an array.

## Errors/Exceptions

Throws an `GmagickException` on error.
