# Removes an image from the image list

## Description

```php
public Gmagick Gmagick::removeimage()
```

Removes an image from the image list.

## Parameters

This function has no parameters.

## Return Values

The `Gmagick` object.

## Errors/Exceptions

Throws an `GmagickException` on error.
