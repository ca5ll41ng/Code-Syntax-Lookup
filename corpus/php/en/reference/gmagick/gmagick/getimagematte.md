# Check if the image has a matte channel

## Description

```php
public int Gmagick::getimagematte()
```

Returns `true` if the image has a matte channel, otherwise `false`.

## Parameters

This function has no parameters.

## Return Values

Returns `true` if the image has a matte channel, otherwise `false`.

## Errors/Exceptions

Throws an `GmagickException` on error.
