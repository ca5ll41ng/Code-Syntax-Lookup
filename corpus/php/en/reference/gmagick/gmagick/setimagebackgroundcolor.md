# Sets the image background color

## Description

```php
public Gmagick Gmagick::setimagebackgroundcolor(GmagickPixel $color)
```

Sets the image background color.

## Parameters

- **`$color`** — The background pixel wand.

## Return Values

The `Gmagick` object.

## Errors/Exceptions

Throws an `GmagickException` on error.
