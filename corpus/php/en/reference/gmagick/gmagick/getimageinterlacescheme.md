# Gets the image interlace scheme

## Description

```php
public int Gmagick::getimageinterlacescheme()
```

Gets the image interlace scheme.

## Parameters

This function has no parameters.

## Return Values

Returns the interlace scheme as an integer on success

## Errors/Exceptions

Throws an `GmagickException` on error.
