# Returns the GraphicsMagick package name

## Description

```php
public string Gmagick::getpackagename()
```

Returns the GraphicsMagick package name.

## Parameters

This function has no parameters.

## Return Values

Returns the GraphicsMagick package name as a string.

## Errors/Exceptions

Throws an `GmagickException` on error.
