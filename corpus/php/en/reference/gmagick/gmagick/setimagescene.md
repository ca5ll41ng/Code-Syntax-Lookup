# Sets the image scene

## Description

```php
public Gmagick Gmagick::setimagescene(int $scene)
```

Sets the image scene.

## Parameters

- **`$scene`** — The image scene number.

## Return Values

The `Gmagick` object.

## Errors/Exceptions

Throws an `GmagickException` on error.
