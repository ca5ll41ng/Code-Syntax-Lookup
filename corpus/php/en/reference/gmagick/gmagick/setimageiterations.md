# Sets the image iterations

## Description

```php
public Gmagick Gmagick::setimageiterations(int $iterations)
```

Sets the image iterations.

## Parameters

- **`$iterations`** — The image delay in 1/100th of a second.

## Return Values

The `Gmagick` object.

## Errors/Exceptions

Throws an `GmagickException` on error.
