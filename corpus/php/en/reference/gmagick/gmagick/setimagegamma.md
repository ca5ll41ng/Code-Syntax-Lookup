# Sets the image gamma

## Description

```php
public Gmagick Gmagick::setimagegamma(float $gamma)
```

Sets the image gamma.

## Parameters

- **`$gamma`** — The image gamma.

## Return Values

The `Gmagick` object.

## Errors/Exceptions

Throws an `GmagickException` on error.
