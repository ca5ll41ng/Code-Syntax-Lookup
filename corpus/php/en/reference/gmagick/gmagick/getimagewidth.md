# Returns the width of the image

## Description

```php
public int Gmagick::getimagewidth()
```

Returns the width of the image.

## Parameters

This function has no parameters.

## Return Values

Returns the image width.

## Errors/Exceptions

Throws an `GmagickException` on error.
