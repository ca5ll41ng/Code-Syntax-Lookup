# Sets the image units of resolution

## Description

```php
public Gmagick Gmagick::setimageunits(int $resolution)
```

Sets the image units of resolution.

## Parameters

- **`$resolution`** — One of the Resolution constant (`Gmagick::RESOLUTION_*`).

## Return Values

The `Gmagick` object.

## Errors/Exceptions

Throws an `GmagickException` on error.
