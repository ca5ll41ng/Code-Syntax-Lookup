# Sets the image depth

## Description

```php
public Gmagick Gmagick::setimagedepth(int $depth)
```

Sets the image depth.

## Parameters

- **`$depth`** — The image depth in bits: 8, 16, or 32.

## Return Values

The `Gmagick` object.

## Errors/Exceptions

Throws an `GmagickException` on error.
