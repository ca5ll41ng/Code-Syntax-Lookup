# Offsets an image

## Description

```php
public Gmagick Gmagick::rollimage(int $x, int $y)
```

Offsets an image as defined by x and y.

## Parameters

- **`$x`** — The x offset.
- **`$y`** — The y offset.

## Return Values

The Gmagick object on success

## Errors/Exceptions

Throws an `GmagickException` on error.
