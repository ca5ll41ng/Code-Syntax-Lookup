# Gets the image delay

## Description

```php
public int Gmagick::getimagedelay()
```

Gets the image delay

## Parameters

This function has no parameters.

## Return Values

Returns the composite operator associated with the image.

## Errors/Exceptions

Throws an `GmagickException` on error.
