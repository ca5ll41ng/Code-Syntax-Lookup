# Set the iterator to the position in the image list specified with the index parameter

## Description

```php
public Gmagick Gmagick::setimageindex(int $index)
```

Set the iterator to the position in the image list specified with the index parameter.

## Parameters

- **`$index`** — The scene number.

## Return Values

The `Gmagick` object.

## Errors/Exceptions

Throws an `GmagickException` on error.
