# Adds a label to an image

## Description

```php
public mixed Gmagick::labelimage(string $label)
```

Adds a label to an image.

## Parameters

- **`$label`** — The label to add

## Return Values

Gmagick with label.

## Errors/Exceptions

Throws an `GmagickException` on error.
