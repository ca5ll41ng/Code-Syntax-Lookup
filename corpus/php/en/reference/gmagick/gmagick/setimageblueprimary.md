# Sets the image chromaticity blue primary point

## Description

```php
public Gmagick Gmagick::setimageblueprimary(float $x, float $y)
```

Sets the image chromaticity blue primary point.

## Parameters

- **`$x`** — The blue primary x-point.
- **`$y`** — The blue primary y-point.

## Return Values

The `Gmagick` object.

## Errors/Exceptions

Throws an `GmagickException` on error.
