# Reads image from filename

## Description

```php
public Gmagick Gmagick::read(string $filename)
```

Reads image from filename.

## Parameters

- **`$filename`** — The image filename.

## Return Values

The `Gmagick` object.

## Errors/Exceptions

Throws an `GmagickException` on error.
