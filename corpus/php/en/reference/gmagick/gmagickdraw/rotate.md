# Applies the specified rotation to the current coordinate space

## Description

```php
public GmagickDraw GmagickDraw::rotate(float $degrees)
```

Applies the specified rotation to the current coordinate space.

## Parameters

- **`$degrees`** — degrees of rotation

## Return Values

The `GmagickDraw` object.
