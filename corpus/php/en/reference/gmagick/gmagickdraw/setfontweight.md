# Sets the font weight

## Description

```php
public GmagickDraw GmagickDraw::setfontweight(int $weight)
```

Sets the font weight to use when annotating with text.

## Parameters

- **`$weight`** — Font weight (valid range 100-900)

## Return Values

The `GmagickDraw` object.
