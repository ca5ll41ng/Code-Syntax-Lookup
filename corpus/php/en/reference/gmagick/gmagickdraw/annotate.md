# Draws text on the image

## Description

```php
public GmagickDraw GmagickDraw::annotate(float $x, float $y, string $text)
```

Draws text on the image.

## Parameters

- **`$x`** — x ordinate to left of text
- **`$y`** — y ordinate to text baseline
- **`$text`** — text to draw

## Return Values

The `GmagickDraw` object.
