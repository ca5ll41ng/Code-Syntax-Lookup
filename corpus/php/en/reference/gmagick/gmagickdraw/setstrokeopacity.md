# Specifies the opacity of stroked object outlines

## Description

```php
public GmagickDraw GmagickDraw::setstrokeopacity(float $stroke_opacity)
```

Specifies the opacity of stroked object outlines.

## Parameters

- **`$stroke_opacity`** — Stroke opacity. The value 1.0 is opaque.

## Return Values

The `GmagickDraw` object.
