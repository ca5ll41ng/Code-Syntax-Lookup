# Draws a bezier curve

## Description

```php
public GmagickDraw GmagickDraw::bezier(array $coordinate_array)
```

Draws a bezier curve through a set of points on the image.

## Parameters

- **`$coordinate_array`** — Coordinates array

## Return Values

The `GmagickDraw` object.
