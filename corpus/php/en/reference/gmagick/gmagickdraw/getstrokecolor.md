# Returns the color used for stroking object outlines

## Description

```php
public GmagickPixel GmagickDraw::getstrokecolor()
```

Returns the color used for stroking object outlines.

## Parameters

This function has no parameters.

## Return Values

Returns an `GmagickPixel` object which describes the color.
