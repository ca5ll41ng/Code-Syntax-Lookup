# Specifies the maximum number of rows to return in the result

## Description

```php
public SolrQuery SolrQuery::setRows(int $rows)
```

Specifies the maximum number of rows to return in the result

## Parameters

- **`$rows`** — The maximum number of rows to return

## Return Values
