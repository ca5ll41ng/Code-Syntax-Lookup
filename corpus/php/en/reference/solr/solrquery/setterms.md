# Enables or disables the TermsComponent

## Description

```php
public SolrQuery SolrQuery::setTerms(bool $flag)
```

Enables or disables the TermsComponent

## Parameters

- **`$flag`** — `true` enables it. `false` turns it off

## Return Values

Returns the current SolrQuery object, if the return value is used.
