# Removes one of the fields used for highlighting

## Description

```php
public SolrQuery SolrQuery::removeHighlightField(string $field)
```

Removes one of the fields used for highlighting.

## Parameters

- **`$field`** — The name of the field

## Return Values

Returns the current SolrQuery object, if the return value is used.
