# Sets collapse hint

## Description

```php
public SolrCollapseFunction SolrCollapseFunction::setHint(string $hint)
```

Sets collapse hint

## Parameters

- **`$hint`** — Currently there is only one hint available "top_fc", which stands for top level FieldCache

## Return Values

`SolrCollapseFunction`
