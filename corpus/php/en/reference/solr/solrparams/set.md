#  `SolrParams::setParam()`

## Description

```php
final public void SolrParams::set(string $name, string $value)
```

An alias of SolrParams::setParam

## Parameters

- **`$name`** — Then name of the parameter
- **`$value`** — The parameter value

## Return Values

Returns an instance of the SolrParams object on success
