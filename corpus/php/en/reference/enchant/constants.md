# Predefined Constants

- **`LIBENCHANT_VERSION` (`string`)** — The version of libenchant. Available as of PHP 8.0.0.
- **`ENCHANT_MYSPELL` (`int`)** — Dictionary type for MySpell. Used with `enchant_broker_get_dict_path()` and `enchant_broker_set_dict_path()`. Deprecated as of PHP 8.0.0.
- **`ENCHANT_ISPELL` (`int`)** — Dictionary type for Ispell. Used with `enchant_broker_get_dict_path()` and `enchant_broker_set_dict_path()`. Deprecated as of PHP 8.0.0.
