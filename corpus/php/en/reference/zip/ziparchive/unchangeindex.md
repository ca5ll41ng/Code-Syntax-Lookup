# Revert all changes done to an entry at the given index

## Description

```php
public bool ZipArchive::unchangeIndex(int $index)
```

Revert all changes done to an entry at the given index.

## Parameters

- **`$index`** — Index of the entry.

## Return Values

Returns `true` on success or `false` on failure.
