# Retrieve last error from libxml

## Description

```php
LibXMLError|false libxml_get_last_error()
```

Retrieve last error from libxml.

## Parameters

This function has no parameters.

## Return Values

Returns a `LibXMLError` object if there is any error in the buffer, `false` otherwise.
