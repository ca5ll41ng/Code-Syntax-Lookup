# Getting Started

## Requirements

The trader extension is based on [TA-Lib](). TA-Lib is fully integrated into the extension, therefore no external libraries are needed.

## Installation

This  extension is not bundled with PHP.

Information for installing this PECL extension may be found in the manual chapter titled Installation of PECL extensions. Additional information such as new releases, downloads, source files, maintainer information, and a CHANGELOG, can be located here: [trader](trader).
