# Vector Log Natural

## Description

```php
array trader_ln(array $real)
```

Calculates the natural logarithm for each value in `$real` and returns the resulting array.

## Parameters

- **`$real`** — Array of real values.

## Return Values

Returns an array with calculated data or false on failure.
