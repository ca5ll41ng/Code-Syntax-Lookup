# Vector Square Root

## Description

```php
array trader_sqrt(array $real)
```

Calculates the square root of each value in `$real` and returns the resulting array.

## Parameters

- **`$real`** — Array of real values.

## Return Values

Returns an array with calculated data or false on failure.
