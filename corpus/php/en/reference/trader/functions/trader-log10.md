# Vector Log10

## Description

```php
array trader_log10(array $real)
```

Calculates the base-10 logarithm for each value in `$real` and returns the resulting array.

## Parameters

- **`$real`** — Array of real values.

## Return Values

Returns an array with calculated data or false on failure.
