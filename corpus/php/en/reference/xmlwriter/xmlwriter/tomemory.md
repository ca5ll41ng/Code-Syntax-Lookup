# Create new `XMLWriter` using memory for string output

## Description

```php
public static static XMLWriter::toMemory()
```

Creates a new `XMLWriter` using memory for string output.

## Parameters

This function has no parameters.

## Return Values

Returns an `XMLWriter`.
