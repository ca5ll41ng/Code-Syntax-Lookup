# Getting Started

## Requirements

The CommonMark extension requires the (C) reference implementation of [cmark](commonmark/cmark).

## Installation

The CommonMark extension releases are hosted by PECL and source is hosted on [github](krakjoe/cmark), the easiest route to installation is the normal PECL route: [cmark](cmark).

Windows users can download prebuilt release binaries from the [PECL](cmark) website.

> Windows users need to take the additional step of adding cmark.dll (distributed with Windows releases) to their PATH.
