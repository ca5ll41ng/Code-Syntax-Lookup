# Checks whether a FFI\CData is a null pointer

## Description

```php
public static bool FFI::isNull(FFI\CData $ptr)
```

Checks whether a FFI\CData is a null pointer.

## Parameters

- **`$ptr`** — The handle of the pointer to a C data structure.

## Return Values

Returns whether a `FFI\CData` is a null pointer.
