# Return true if the RightInfo concern grants access to the resource

## Description

```php
final public bool Win32Service\RightInfo::isGrantAccess()
```

Return `true` if the RightInfo concern grants access to the resource, `false` otherwise.

## Parameters

This function has no parameters.

## Return Values

 {{{ 

Return `true` if the RightInfo concern grants access to the resource, `false` otherwise.
