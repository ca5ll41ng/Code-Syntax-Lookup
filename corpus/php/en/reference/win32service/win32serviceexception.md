# The Win32ServiceException class

Win32ServiceException

   Introduction  The exception replaces the old mechanism where the error value needed to be compared to constants to detect which error was emitted. The Exception code is equal to the value of the error value and the exception message is based on the corresponding constant name.      Class Synopsis   `Win32ServiceException`    `Win32ServiceException`   `extends` `Exception`
