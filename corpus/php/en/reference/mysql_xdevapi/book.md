# Mysql_xdevapi

Mysql_xdevapi

 Introduction  This extension provides access to the MySQL Document Store via the X DevAPI. The X DevAPI is a common API provided by multiple MySQL Connectors providing easy access to relational tables as well as collections of documents, which are represented in JSON, from a API with CRUD-style operations.    The X DevAPI uses the X Protocol, the new generation client-server protocol of the MySQL 8.0 server.    For general information about the MySQL Document Store, please refer to the [MySQL Document Store]() chapter in the MySQL manual.
