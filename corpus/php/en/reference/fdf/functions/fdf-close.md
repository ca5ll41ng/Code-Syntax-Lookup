# Close an FDF document

## Description

```php
void fdf_close(resource $fdf_document)
```

Closes the FDF document.

## Parameters

- **`$fdf_document`** — The FDF document handle, returned by `fdf_create()`, `fdf_open()` or `fdf_open_string()`.

## Return Values

No value is returned.
