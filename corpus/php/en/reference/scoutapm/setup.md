# Getting Started

## Requirements

- PHP >= 7.1.0
- Windows is not currently supported

## Installation

This extension is available on PECL. Run:

```text

    
$ sudo pecl install scoutapm

   
```

You may need to add Scout to your *php.ini*, for example:

```text


extension=scoutapm.so

   
```
