# Returns the named image profile

## Description

```php
public string Imagick::getImageProfile(string $name)
```

Returns the named image profile.

## Parameters

- **`$name`** — The name of the profile to return.

## Return Values

Returns a string containing the image profile.

## Errors/Exceptions

Throws ImagickException on error.
