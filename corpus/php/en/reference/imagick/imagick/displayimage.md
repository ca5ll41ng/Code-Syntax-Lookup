# Displays an image

## Description

```php
public bool Imagick::displayImage(string $servername)
```

This method displays an image on a X server.

## Parameters

- **`$servername`** — The X server name

## Return Values

Returns `true` on success.

## Errors/Exceptions

Throws ImagickException on error.
