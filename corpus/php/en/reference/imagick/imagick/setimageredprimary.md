# Sets the image chromaticity red primary point

## Description

```php
public bool Imagick::setImageRedPrimary(float $x, float $y)
```

Sets the image chromaticity red primary point.

## Parameters

- **`$x`**
- **`$y`**

## Return Values

Returns `true` on success.

## Errors/Exceptions

Throws ImagickException on error.
