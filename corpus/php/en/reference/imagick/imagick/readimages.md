# Reads image from an array of filenames

## Description

```php
public bool Imagick::readImages(array $filenames)
```

Reads image from an array of filenames. All the images are held in a single Imagick object.

## Parameters

- **`$filenames`**

## Return Values

Returns `true` on success.
