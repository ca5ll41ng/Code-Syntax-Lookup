# Sets the depth of a particular image channel

## Description

```php
public bool Imagick::setImageChannelDepth(int $channel, int $depth)
```

Sets the depth of a particular image channel.

## Parameters

- **`$channel`**
- **`$depth`**

## Return Values

Returns `true` on success.

## Errors/Exceptions

Throws ImagickException on error.
