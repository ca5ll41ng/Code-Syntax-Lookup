# Gets the image total ink density

## Description

```php
public float Imagick::getImageTotalInkDensity()
```

Gets the image total ink density.

## Parameters

This function has no parameters.

## Return Values

Returns the image total ink density of the image. Throw an `ImagickException` on error.
