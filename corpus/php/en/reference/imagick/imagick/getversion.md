# Returns the ImageMagick API version

## Description

```php
public static array Imagick::getVersion()
```

Returns the ImageMagick API version as a string and as a number.

## Parameters

This function has no parameters.

## Return Values

Returns the ImageMagick API version as a string and as a number.

## Errors/Exceptions

Throws ImagickException on error.
