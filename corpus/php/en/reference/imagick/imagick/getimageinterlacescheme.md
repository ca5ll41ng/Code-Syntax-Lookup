# Gets the image interlace scheme

## Description

```php
public int Imagick::getImageInterlaceScheme()
```

Gets the image interlace scheme.

## Parameters

This function has no parameters.

## Return Values

Returns the interlace scheme as an integer on success. Throw an `ImagickException` on error.
