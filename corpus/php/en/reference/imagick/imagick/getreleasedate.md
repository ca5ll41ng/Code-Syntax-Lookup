# Returns the ImageMagick release date

## Description

```php
public static string Imagick::getReleaseDate()
```

Returns the ImageMagick release date as a string.

## Parameters

This function has no parameters.

## Return Values

Returns the ImageMagick release date as a string.

## Errors/Exceptions

Throws ImagickException on error.
