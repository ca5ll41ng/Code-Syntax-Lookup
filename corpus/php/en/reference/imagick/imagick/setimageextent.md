# Sets the image size

## Description

```php
public bool Imagick::setImageExtent(int $columns, int $rows)
```

Sets the image size (i.e. columns & rows).

## Parameters

- **`$columns`**
- **`$rows`**

## Return Values

Returns `true` on success.

## Errors/Exceptions

Throws ImagickException on error.
