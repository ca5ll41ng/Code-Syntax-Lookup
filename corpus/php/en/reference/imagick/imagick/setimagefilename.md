# Sets the filename of a particular image

## Description

```php
public bool Imagick::setImageFilename(string $filename)
```

Sets the filename of a particular image in a sequence.

## Parameters

- **`$filename`**

## Return Values

Returns `true` on success.

## Errors/Exceptions

Throws ImagickException on error.
