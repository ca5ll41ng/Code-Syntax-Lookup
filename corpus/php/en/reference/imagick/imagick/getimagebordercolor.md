# Returns the image border color

## Description

```php
public ImagickPixel Imagick::getImageBorderColor()
```

Returns the image border color.

## Parameters

This function has no parameters.

## Return Values

Returns `true` on success.

## Errors/Exceptions

Throws ImagickException on error.
