# Returns a new Imagick object

## Description

```php
public Imagick Imagick::getImage()
```

Returns a new Imagick object with the current image sequence.

## Parameters

This function has no parameters.

## Return Values

Returns a new Imagick object with the current image sequence.

## Errors/Exceptions

Throws ImagickException on error.
