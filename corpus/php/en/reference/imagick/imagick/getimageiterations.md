# Gets the image iterations

## Description

```php
public int Imagick::getImageIterations()
```

Gets the image iterations.

## Parameters

This function has no parameters.

## Return Values

Returns the image iterations as an integer.

## Errors/Exceptions

Throws ImagickException on error.
