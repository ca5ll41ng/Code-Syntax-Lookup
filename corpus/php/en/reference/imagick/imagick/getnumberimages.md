# Returns the number of images in the object

## Description

```php
public int Imagick::getNumberImages()
```

Returns the number of images associated with Imagick object.

## Parameters

This function has no parameters.

## Return Values

Returns the number of images associated with Imagick object.

## Errors/Exceptions

Throws ImagickException on error.
