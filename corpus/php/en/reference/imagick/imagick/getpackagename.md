# Returns the ImageMagick package name

## Description

```php
public static string Imagick::getPackageName()
```

Returns the ImageMagick package name.

## Parameters

This function has no parameters.

## Return Values

Returns the ImageMagick package name as a string.

## Errors/Exceptions

Throws ImagickException on error.
