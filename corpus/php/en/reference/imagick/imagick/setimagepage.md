# Sets the page geometry of the image

## Description

```php
public bool Imagick::setImagePage(int $width, int $height, int $x, int $y)
```

Sets the page geometry of the image.

## Parameters

- **`$width`**
- **`$height`**
- **`$x`**
- **`$y`**

## Return Values

Returns `true` on success.

## Errors/Exceptions

Throws ImagickException on error.
