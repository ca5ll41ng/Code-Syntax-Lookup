# Sets the color of the specified colormap index

## Description

```php
public bool Imagick::setImageColormapColor(int $index, ImagickPixel $color)
```

Sets the color of the specified colormap index.

## Parameters

- **`$index`**
- **`$color`**

## Return Values

Returns `true` on success.

## Errors/Exceptions

Throws ImagickException on error.
