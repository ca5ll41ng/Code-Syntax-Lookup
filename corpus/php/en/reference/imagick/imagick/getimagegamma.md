# Gets the image gamma

## Description

```php
public float Imagick::getImageGamma()
```

Gets the image gamma.

## Parameters

This function has no parameters.

## Return Values

Returns the image gamma on success.

## Errors/Exceptions

Throws ImagickException on error.
