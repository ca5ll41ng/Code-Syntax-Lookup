## Description

```php
public bool Imagick::quantizeImages(int $numberColors, int $colorspace, int $treedepth, bool $dither, bool $measureError)
```

## Parameters

- **`$numberColors`**
- **`$colorspace`**
- **`$treedepth`**
- **`$dither`**
- **`$measureError`**

## Return Values

Returns `true` on success.

## Errors/Exceptions
