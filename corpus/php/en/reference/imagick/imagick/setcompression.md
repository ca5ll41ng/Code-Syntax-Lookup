# Sets the object's default compression type

## Description

```php
public bool Imagick::setCompression(int $compression)
```

Sets the object's default compression type

## Parameters

- **`$compression`** — The compression type. See the Imagick::COMPRESSION_* constants.

## Return Values

Returns `true` on success.
