# Sets the image interpolate pixel method

## Description

```php
public bool Imagick::setImageInterpolateMethod(int $method)
```

Sets the image interpolate pixel method.

## Parameters

- **`$method`** — The method is one of the `Imagick::INTERPOLATE_{*}` constants

## Return Values

Returns `true` on success.
