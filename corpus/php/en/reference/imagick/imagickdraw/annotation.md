# Draws text on the image

## Description

```php
public bool ImagickDraw::annotation(float $x, float $y, string $text)
```

> This function is currently not documented; only its argument list is available.

Draws text on the image.

## Parameters

- **`$x`** — The x coordinate where text is drawn
- **`$y`** — The y coordinate where text is drawn
- **`$text`** — The text to draw on the image

## Return Values

No value is returned.
