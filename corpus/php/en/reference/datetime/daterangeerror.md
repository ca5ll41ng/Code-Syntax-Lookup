# The DateRangeError class

DateRangeError

   Introduction  Thrown by `DateTime::getTimestamp()`, `DateTimeImmutable::getTimestamp()`, and `date_timestamp_get()`, on 32-bit platforms if the date object represents a date outside of the 32-bit signed range.      Class Synopsis    DateRangeError   `extends` `DateError`           See Also  DateError DateObjectError
