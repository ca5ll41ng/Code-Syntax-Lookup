# The DateMalformedStringException class

DateMalformedStringException

   Introduction  Thrown when an invalid Date/Time string is detected.    This can be as value to `DateTimeImmutable::__construct()`, `DateTimeImmutable::modify()`, `DateTime::__construct()`, or `DateTime::modify()`.      Class Synopsis    DateMalformedStringException   `extends` `DateException`
